# Client dashboard library

Purpose: reference base for the client dashboard and report redesign (see `00_project/client-dashboard-redesign/`).
Each folder has one `extract.md`: sources, findings, recommendation per data point (IDs D01–D49 from `01-inventory.md`), and `refs/` with screenshots for decision cards.
Rules: product pages and docs count as current on their fetch date. Evergreen design principles are allowed and marked `evergreen`. Blog posts and videos older than 3 months are dropped unless evergreen.
Screenshots are for internal decisions only. They never go into client files.
In client files, call the framework "741 Dashboard-Raster". Never name the sources.
