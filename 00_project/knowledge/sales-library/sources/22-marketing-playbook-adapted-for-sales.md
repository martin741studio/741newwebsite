## Findings
- IF a prospect gets a cold DM, a call, or an ad, THEN the prospect checks the founder's profile first. — Src: channel-selection §1, `pass that "legitimacy test"`.
- IF organic posts are running, THEN report them as proof for outreach, never as pipeline. — Src: grill-rules R-MG1.2, "not the primary lead source".
- **IF pipeline is needed now, THEN run outreach and paid ads first, because organic needs 12-18 months.** — Src: channel-selection §1, "should NOT be the primary early lever".
- IF a post angle wins organically, THEN reuse that angle in the outreach copy. — Src: channel-selection §1, "winning organic angles can be fed directly into cold-outbound sequences".
- **IF the first touch to a cold prospect is a booking link, THEN expect low conversion and offer a free audit first.** — Src: visibility-leads Part 5, "results in low conversions because cold prospects lack trust".
- **IF the review page goes to a cold prospect, THEN frame it as a reveal-a-problem lead magnet, not a pitch.** — Src: visibility-leads Part 5, "Reveal a Problem (Audits & Diagnostics)".
- IF a prospect searches for the service now, THEN treat the lead as high intent, with volume capped. — Src: visibility-leads Part 1 §3, "High intent, highest lead quality, but limited by search volume".
- IF an inbound request arrives, THEN reply within 60 seconds where possible. — Src: visibility-leads Part 6 §2, "within 60 seconds increases sales conversion by 391%" (source figure, not 741 data).
- IF a warm contact is messaged, THEN personalize the message from past context. — Src: visibility-leads Method 1, "Personalize every message based on past context".
- IF a warm contact is offered help, THEN make the first step zero-friction, then move to paid work. — Src: visibility-leads Method 1, "Present a zero-friction or free offer to initiate work".
- IF a satisfied past contact knows a fitting prospect, THEN invite a referral. — Src: visibility-leads Method 1, "Invite referrals from satisfied contacts".
- IF a cold prospect is messaged, THEN make the first line specific and give fast value. — Src: visibility-leads Method 2, "Make the initial line specific so it doesn't look like mass spam".
- IF a cold prospect does not reply, THEN follow up across several touchpoints. — Src: visibility-leads Method 2, "consistent follow-ups across multiple touchpoints".
- IF referral capacity is free, THEN start customer referrals before partners or agencies. — Src: grill-rules R-MG2.2, "customer referrals (highest LTV, lowest CAC)".
- IF LinkedIn content is posted, THEN keep value posts near a 3.5:1 or 4:1 ratio against asks. — Src: visibility-leads Method 3, "3.5:1 or 4:1 ratio".
- IF a post needs a review-page or booking link, THEN place the link in the first comment. — Src: strategy-notes, "Put a link in the first comment instead".
- IF the founder posts, THEN keep posts from turning into agency promotion. — Src: content-brief, "Do not turn every personal post into an agency promotion.".
- IF LinkedIn posting runs, THEN post 3-5 times per week, not daily. — Src: channel-selection §3, "Posting cadence on B2B platforms" (3-5x/week).
- IF a new outreach channel is judged, THEN run it 100 actions per day for 100 days first. — Src: grill-rules R-MG3.2, "100 consecutive days before judging it".
- IF the outreach seat underperforms, THEN diagnose the break before adding volume. — Src: grill-rules R-MG3.1, "diagnose the specific break".
- IF the weekly sales brief covers the one seat, THEN show reply status and the restriction-or-tool diagnosis first. — Src: mkt-playbook §4, "same-day reply status and the restriction-vs-tool diagnosis".
- IF more than one seat runs, THEN prove and scale the first seat before adding a second. — Src: mkt-playbook §2, "fixed and proven before a second seat is added".
- IF the close rate is unproven, THEN fix the offer before adding outreach volume. — Src: grill-rules R-MG1.4, "fix the offer before scaling any channel".
- **IF a prospect has a visibility problem, THEN ask in week one: found or booked?** — Src: benchmark §3, "Gefunden, aber nicht gebucht" (not in 741 files).
- IF a prospect is found but not booked, THEN check the booking path: phone, intake, reply speed, price. — Src: benchmark §7 Angebot, "Für 'gebucht' fehlt ein sichtbarer Baustein".
- PROPOSAL for Martin: IF he approves it, THEN a guarantee may count new inquiries in 90 days, not only rank. — Src: benchmark §7 Claim, "Eine Zahl wie 'X neue Anfragen in 90 Tagen'".
- IF a guarantee is written for a done-for-you service, THEN add no attendance or homework conditions. — Src: benchmark §7 "Was 741 nicht übernehmen sollte", "wäre das ein Widerspruch".
- **CONFLICT: IF a prospect asks about refunds, THEN use the call-raster rule, not the einwand refund line.** — Src: einwand Garantie-Baustein, "du bekommst dein Geld zurück"; call-raster Phase 4, "Do not promise money back.".
- IF the team quotes a price, THEN say "Dein Preis: 4.999 € für das 90-Tage-Programm", not the einwand 3.699 figure. — Src: call-raster Phase 4, "Dein Preis: 4.999 € für das 90-Tage-Programm".
- IF a prospect compares agencies, THEN say everything belongs to them from day one (verify access claim first). — Src: benchmark §7 Angebot, "Du mietest nichts. Alles gehört dir ab Tag 1".
- IF a pitch claim is drafted, THEN name the person, moment, number, deadline and rival. — Src: benchmark §7 Claim, "Person, Moment, Zahl, Frist, Feind".
- IF the benchmark's programme price comes up, THEN note it is unknown and never use it as an anchor. — Src: benchmark §5, "Preis des Programms steht nirgends".
- DECISION for Martin: IF a price goes on the website, THEN note the 741 rule forbids written prices before the call. — Src: benchmark §4 d, "Preis auf der Website" vs call-raster "No price in writing before the call".
- DECISION for Martin: IF the team tests a shorter first call, THEN note the benchmark uses 10-15 minutes, 741 uses 60. — Src: benchmark §4 e, "Erstgespräch 10 bis 15 Minuten".
