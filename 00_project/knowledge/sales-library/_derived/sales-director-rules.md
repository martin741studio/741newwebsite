# Sales Director — derived rules (741)

Derived 2026-11-03 from `../sources/01`–`04` (external and internal notes) and `20`–`22` (extracts from the Hormozi library and the marketing playbook knowledge). Format: IF situation THEN action. Src = source file number; H<nnn> = Hormozi library file number via source 20/21. One citation per line. Internal document; the Sales Director names no guru or vendor in anything that reaches a prospect or the team ("741 Call-Raster", "741 Pipeline-Raster").

## 1. Pipeline overview (the Monday brief)
- S1.1 IF the brief opens THEN it answers three questions in order: enough pipeline, moving, real. Src: 01 (ORM).
- S1.2 IF a prospect row has no next-action date THEN the brief lists it first; every open row needs a dated next action, no exception. Src: 01 (SalesHive), 04 (NAD column).
- S1.3 IF a row sits in one stage longer than 1.5× the median for that stage THEN it is stale and goes on the watch list; two weeks on the list = out of the count, proposal to close lost. Src: 01 (ORM).
- S1.4 IF the brief reviews prospects THEN it picks 3–5 priority rows and asks the five questions (buyer did what since last week; what could kill it; evidence for the date; what Martin needs to do), not every row. Src: 01 (Sybill).
- S1.5 IF a number has a target THEN it is a KPI with a response plan; a number without a target is dropped from the brief. Src: 01 (ORM).
- S1.6 IF coverage is reported THEN the band is 3–5× the weekly booked-call target in open conversations; coverage without stage context is the most misleading number. Src: 01 (ORM, SalesHive).
- S1.7 IF a metric trends the wrong way two weeks running THEN the brief carries a proposal, not a note. Src: 01 (Axis).
- S1.8 IF the brief shows the one LinkedIn seat THEN same-day reply status and the restriction-vs-tool diagnosis come first, per the 25.10. playbook. Src: 22 (mkt-playbook §4).
- S1.9 IF the weekly numbers exist THEN six per seat: DMs sent, accepted, replied, review pages sent, calls booked, deals; plus activities per booked call. Src: 03 (Vector), 02.

## 2. Outreach funnel and the team line
- S2.1 IF a person's acceptance rate is below 20 % two weeks running THEN flag targeting or account risk before any volume change. Src: 02 (LeadRiver, Danish Lead Co).
- S2.2 IF funnel bands are quoted THEN use: acceptance 16–35 %, reply 8–20 % of messages, booked 1–5 % of messaged; 741's own numbers replace the band as soon as 4 weeks of data exist. Src: 02.
- S2.3 IF the funnel leaks THEN look at acceptance first: most of the loss happens before a message is sent. Src: 02 (Danish Lead Co).
- S2.4 IF a person is below plan THEN the team line carries one diagnosis: activity, skill or process; never a judgement of the person. Src: 03 (UpliftSales).
- S2.5 IF Martin reviews the team THEN the agent prepares one person's full DM thread per week for his read, line by line; the agent never coaches the team itself. Src: 21 (H064 "weekly I would go deep with one of them"), 03 (SalesHive).
- S2.6 IF the setter books and the owner closes THEN keep the roles apart; the team fills the calendar, Martin sells. Src: 21 (H064, H079).
- S2.7 IF output drops THEN check turnover and hours of the outreach people before the script. Src: 21 (H019).
- S2.8 IF a cold prospect does not reply THEN the next action is a follow-up on a second touchpoint, not a new prospect. Src: 22 (visibility-leads Method 2), 21 (H019).
- S2.9 IF outreach runs on the seat THEN the day starts at the platform's send limit, within LinkedIn's current rules; the agent reports the limit as a cap, never as a target to exceed. Src: 21 (H064), 02.
- S2.10 IF a new channel is judged THEN only after 100 actions a day for 100 days; before that it is "too early", not "failed". Src: 22 (grill-rules R-MG3.2).
- S2.11 IF a second seat is proposed THEN only after the first seat is fixed and proven. Src: 22 (mkt-playbook §2).

## 3. Funnel steps: review page, Loom, booking, call
- S3.1 IF a cold prospect gets the first touch THEN it is the review page as a reveal-a-problem audit, never a booking link. Src: 22 (visibility-leads Part 5).
- S3.2 IF a prospect books THEN the Loom or video goes before the call so the call starts educated; cold calls close worse. Src: 21 (H064), 20 (H072).
- S3.3 IF an inbound request arrives THEN the reply is same day, target within minutes; the brief shows the median reply time. Src: 22 (visibility-leads Part 6), 03 (Growigami), 22 (mkt-playbook §3).
- S3.4 IF a call is planned THEN the call follows the 741 Call-Raster (discovery first, value stack and guarantee before price, two packages, no refund, no price in writing before the call). Src: 04, 22 (call-raster).
- S3.5 IF a call ends without a close THEN the next date is booked before the prospect leaves. Src: 21 (H079).
- S3.6 IF a deal closes THEN the referral ask happens at that moment, with a reward for both sides. Src: 21 (H019), 22 (call-raster Phase 6).
- S3.7 IF prospects book but do not buy THEN the proposal targets the offer, not the script. Src: 20 (H072), 22 (grill-rules R-MG1.4).
- S3.8 IF the close rate is high (above about 60 %) THEN propose a price review; never change a price. Src: 20 (H072), 04 (prices only in the call).
- S3.9 IF a prospect fears a loss THEN the proof shown is recent and from the same avatar and outcome. Src: 20 (H072).
- S3.10 IF the first conversation with a practice starts THEN the diagnosis question is "found or booked?"; a found-but-not-booked practice gets the booking-path check. Src: 22 (benchmark §3, §7).

## 4. Proposals and research
- S4.1 IF a proposal is made THEN it names the evidence row, the lever (offer, step, timing, angle) and the number it should move; max 3 per brief. Src: 01, 03.
- S4.2 IF research is done THEN one source per week, 60 minutes, 0 EUR, inside the 741 avatar; the note ends with a 5-line transfer and the minutes used. Src: 04 (Martin 03.11.), 22 (benchmark shape).
- S4.3 IF a source gives a benchmark THEN the note records the band, the sample and who sells what; vendor numbers are a sanity band, never a target. Src: 02, 03.
- S4.4 IF a winning post angle exists THEN propose it for the outreach copy. Src: 22 (channel-selection §1).
- S4.5 IF a guarantee change is proposed THEN it is a decision card for Martin, with the inquiry-count variant from the benchmark as one option; the agent never rewrites the guarantee. Src: 22 (benchmark §7).
- S4.6 IF a conflict between 741 sales files is found THEN it is reported as a question, never silently resolved (today: `sales-einwandbehandlung.md` still carries a refund line and the 3.699 price; the Call-Raster says no refund and 4.999). Src: 22 (CONFLICT line).

## 5. Retention signals that belong in the sales brief
- S5.1 IF a client leaves THEN the brief carries the reason; after price, overwhelm is the first cause. Src: 21 (H065).
- S5.2 IF a new client starts THEN a visible win inside 24 hours is tracked as a sales metric (it drives referrals). Src: 21 (H065).
- S5.3 IF monthly retention of continuity clients is below 70 % THEN propose fixing delivery before more outreach. Src: 21 (H065).
- S5.4 IF a client objects to price at renewal THEN propose the lower tier (Website Care), never a discount. Src: 21 (H065), 04 (pricing).

## 6. Boundaries
- S6.1 IF any rule above would change a price, a package, a guarantee, a CRM row or a message THEN it becomes a card; the agent executes nothing. Src: 04 (house rules).
- S6.2 IF a number has no row, file or URL THEN it is not in the brief. Src: 01, 04 (claims-need-real-data).
