# About access levels in your Google Ads account

Each time you grant access to your Google Ads account, you can select the features a user can impact by assigning an access level.

This article explains the different access levels and their corresponding features. It also provides information on how to identify the appropriate admin user for tasks such as setting up monthly invoicing or applying for a credit line.

Learn how to grant or remove access to your Google Ads account.

**Note**: If your account has only one administrator, you may lose access to your tags if that user becomes unavailable. Adding at least one additional administrator to your account may help ensure uninterrupted tag management. You’ll find a Tag Diagnostics notification if your account is identified as having only one admin. If you lose access to your tags, reach out to support by clicking the Contact us button at the bottom of the Google Ads Help Center.

### Access for manager accounts

If you've accepted an invitation to link to a manager account, users with admin access to the manager account can receive notification emails and manage your campaigns. If the manager account has ownership, users with admin access to the manager account can also edit user access, managers, and product links within your account.

For monthly invoicing or credit line applications, ensure that manager account ownership is enabled and the request is authorized by an admin of the Google Ads child account or the manager account admin. Learn more about manager account access levels.

### Access to billing and payments

Within Google Ads, users with Admin or Billing access levels can update an organization's payments profile info, such as the following:

- Name and address
- Tax ID
- Language preference
- Add and edit forms of payment

Users with Admin or Billing access can make these changes even if they aren't Payments profile users. Admins can also complete all steps of the advertiser verification process. These actions were previously restricted to Payments profile users only.

When Google Ads users make changes to the payments profile, payments admins receive an email notification.

**Note**: Google Ads users can't directly add or remove users from the payments profile or change existing user permissions. To request changes to payment users, the primary contact on the payments profile, or a user within the same company domain as the primary contact, needs to contact Google Ads support. When contacting support, include the full name, email address (linked to a Google Account), phone number, and desired permissions for each user you want to add or modify. Also include your Payments Profile ID. Learn more about payments user permissions.

If you want to turn this feature off, contact Google Ads support.

### Conversions integration

Users with Standard and Admin access can help create conversions directly from Google Analytics events and key events, seamlessly sharing these with Google Ads. These conversions will be available for use in reporting and bidding within Google Ads.

**Note**: Certain settings may be managed solely within Google Analytics for consistency across platforms.
