# A05 How to Disavow Toxic Backlinks in 2026: Google's Disavow Tool, Step by Step
Source: articles/A05-auspia-how-to-disavow-2026.md, ARTICLE, published 2026-09-03, Julian Mercer / Auspia, https://auspia.ai/blog/how-to-disavow-toxic-backlinks-2026
Reliability: Medium. Practitioner guide that follows Google's docs closely. Vendor blog.

## Practice from this source
- Gate before any disavow: manual action or own link scheme = disavow after removal attempts. Third-party "toxic" flag = do not disavow yet. Ranking drop without manual action = investigate first.
- Use the Search Console Links export as the master list. Do not import third-party "toxic" flags into the disavow file. "Toxicity scores are not evidence of a manual action."
- Log removal attempts (URL, contact route, date, result).
- Use `#` comments in the file with date and reason. They are the only audit trail inside Google's tool.
- One list per property. Each upload replaces the last. Keep the master copy.
- If an upload fails, the old list stays active.
- Disavowed links still appear in the Links report. That is not a failure.
- Judge effects after weeks to months, not days.
- Mistakes: disavowing from a tool flag, malformed `domain:https://` lines, disavowing own domain or real editorial links.

## Use for client-access-lockout
- A/C: Apply the gate table to the client's audit. Without a manual action, the answer is "do not disavow yet".
- D: Comment lines in a disavow file and a removal log are evidence of who did what and when.
