# O02 Search Console Help: Disavow links to your site
Source: official-docs/gsc-disavow-links.md, OFFICIAL, living page fetched 2026-10-12, https://support.google.com/webmasters/answer/2648487?hl=en
Reliability: High. Google's own rules for the disavow tool.

## Practice from this source
- Google calls disavow "an advanced feature" to use "with caution". Wrong use "can potentially harm your site's performance".
- "In most cases, Google can assess which links to trust without additional guidance, so most sites will not need to use this tool."
- Disavow only if BOTH are true: a considerable number of spammy, artificial or low-quality links, AND the links caused, or likely will cause, a manual action.
- Google says it "works very hard to make sure that actions on third-party sites do not negatively affect a website".
- Google names the realistic risk: "you or an SEO that you've hired may have built bad links". First try to remove such links.
- File rules: .txt, UTF-8 or 7-bit ASCII, one URL or `domain:` per line, `#` comments allowed, max 100,000 lines and 2 MB.
- "Uploading a new list for a property will replace any existing list for that property." The upload is not additive.
- If the new file has errors, the old list stays active.
- "You must be a property owner to upload a disavow list."
- The tool does not support Domain properties. It works on URL-prefix properties. Lists apply to child properties.
- Disavowed links still show in the Links report.
- Effect takes "a few weeks" as Google recrawls. "Cancel Disavowals" removes the whole list, with the same delay.

## Use for client-access-lockout
- A/C: A third-party list of spam domains is not a reason to disavow. Check first for a manual action (O05).
- C: Before any change, record the current disavow state (summary on the tool page). A new upload replaces it.
- B: Only an owner can upload. If the client removed the agency, the agency cannot change or remove a disavow file. Any upload after that date is not the agency's action.

## Limits
- The page does not describe a "download current list" function. It only says a summary of disavowed pages and domains is shown. Verify in the live tool.
