# O05 Search Console Help: Manual actions report
Source: official-docs/gsc-manual-actions-report.md, OFFICIAL, living page fetched 2026-10-12, https://support.google.com/webmasters/answer/9044175?hl=en
Reliability: High. Google Search Console Help.

## Practice from this source
- Google notifies a manual action "in the Manual actions report and in the Search Console message center".
- With no manual action, the report shows "a green check mark and an appropriate message".
- "Unnatural links to your site" is the link manual action. Google says it means "a pattern of unnatural, artificial, deceptive, or manipulative links".
- Fix steps: export links, check them against the link spam policy, ask site owners to remove or nofollow, then disavow what you cannot remove.
- "Blindly adding all backlinks to the disavow file is not considered a good-faith effort."
- "Make sure that you don't disavow organic links to your site."
- After the fix, request review and document removed links and failed removals.
- Link reconsideration can take longer than "several days or weeks".

## Use for client-access-lockout
- A: The first technical check for any "your backlinks are toxic" claim is this report. A green check means no manual penalty.
- D: Take a dated screenshot of the report. It is strong evidence for the client.
- C: Without a manual action, Google's own process for link clean-up does not start.

## Limits
- Algorithmic effects (spam updates) do not show here. A green check does not prove that rankings are unaffected by other causes.
