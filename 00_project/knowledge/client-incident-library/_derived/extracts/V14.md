## Practice from this source
- Add the site as a "Domain" property. It covers all subdomains, www and non-www, HTTP and HTTPS.
- A Domain property needs DNS verification with a TXT record. For a webmaster this is "a 2-minute job."
- User access lives under Settings. The video does not explain user roles in detail.
- The "Security and manual actions" section is the one "you honestly hope stays empty."
- The Links report shows top linked pages, internal links, and which sites link to the site. It is free.
- The Links report gives no link quality scores. It is "your link profile straight from Google."
- Search Console keeps up to 16 months of data. Use compare mode, for example last 3 months against the previous period.
- To find the cause of a traffic drop: compare periods, then sort pages by click difference ascending. The biggest losers come to the top.
- Average position is an average over all impressions. Treat it as a trend line, not an exact rank.
- Do not react to small moves on low-volume keywords.
- Filter out brand terms with a regex "doesn't match" filter. The rest is non-branded performance.
- A non-branded clicks comparison proves content growth "with Google's own data behind it."
- "Not indexed" is not always an error. Thank-you pages, ad landing pages and test pages should stay out of the index.
- URL inspection shows index status and last crawl. "Request indexing" has a daily quota and no guarantee.

## Use for client-access-lockout
- A Verification of claims: open the Manual actions report. If it is empty, Google has no manual penalty on the site. Open the Links report to check if the "spam domains" even appear.
- D Evidence and documentation: export the 16-month performance data, the non-branded compare and the top pages. This is Google's own proof of the agency's work.
- B Account ownership and access: the owner verifies the Domain property by DNS and controls users in Settings. Collect GSC evidence before access ends, if possible.
- E Contract and pausing work: the video shows that drop analysis, indexing checks and reporting all need GSC. Without access, these tasks stop.
