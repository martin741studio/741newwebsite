# A36 How to Run Agency Project Management in 2026? Full Guide
Source: articles/A36-productive-agency-project-management-guide.md, ARTICLE, published 2026-08-23, Marija Kata Vlašić / Productive.io blog, https://productive.io/blog/agency-project-management-guide/
Reliability: Agency software vendor guide. It sells a project management tool. The relevant parts (status record, change log, update rhythm) are general good practice. Only a small part is about evidence.

## Practice from this source
- Keep status in one place. The article warns that status often "lives in four places".
- Each project record needs four fields: current stage, owner, next action, and whether the date is at risk.
- A client portal helps only if it reads the same record, not a copy.
- Log every change request in writing. Quote anything above a set threshold, for example two hours, before work starts.
- The article says small unlogged requests add up to a week of unpaid work.
- Log time daily against the calendar. A week-old entry is a guess, not a record.
- Send a weekly four-line update: what shipped, what is next, what you need from the client, and whether the date moved.
- Send the update on the same day each week, even when nothing moved.
- For retainers, report hours used against hours bought every month.
- Write the update rhythm into the contract.

## Use for client-access-lockout
- D Evidence and documentation: one dated record of tasks, changes and approvals is the base of our evidence file.
- D Evidence and documentation: regular written updates are proof of work and prevent the "nothing happened" doubt.
- F Communication with a mistrustful client: the four-line update format suits a short status message to the client.
