# A09 Google Ads Agency Account Ownership: Who Owns What, and How Exposed Are You
Source: articles/A09-kampaio-google-ads-agency-account-ownership.md, ARTICLE, published 2026-07-27, Kampaio (Google Ads software vendor), https://www.kampaio.com/blog/google-ads-agency-account-ownership
Reliability: Medium-high. Checked against Google Ads Help (2026). Vendor bias: sells software as an agency alternative.

## Practice from this source
- A Google Ads account has exactly one owner. If the agency's manager account created it, the agency is owner.
- Clean set-up: the client creates the account under a company-domain email, then links the agency's manager account.
- Only Admin can unlink managers. A client with Standard access "can edit every campaign and still not remove the agency".
- Six assets can be stranded separately: Ads ownership, own access level, payments profile, conversion tags/GTM, GA4 property and link, audiences and Merchant Center.
- Six contract points: client creates account; client keeps Admin plus a second person; payments profile with the client; GTM in the client's account; GA4 owned by the client; written offboarding clause with access handover within a set number of business days, not tied to final invoice.
- "Most disputes ... are about ownership used as a bargaining chip during a billing disagreement."
- If access is missing: request in writing, document with dated screenshots, then escalate to Google support. Google support helps with access but does not arbitrate the contract.

## Use for client-access-lockout
- B/H: The agency must never use access as a bargaining chip. The client owns her accounts; the agency is a linked user.
- E/H: Put the access handover and offboarding clause into the contract, independent of open invoices.
- D: Dated screenshots of access screens are standard evidence.

## Limits
- Written from the advertiser's side and for Google Ads only.
