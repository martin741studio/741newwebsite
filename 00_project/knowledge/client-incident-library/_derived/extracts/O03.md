# O03 Search Console Help: Verify your site ownership
Source: official-docs/gsc-verify-site-ownership.md, OFFICIAL, living page fetched 2026-10-12, https://support.google.com/webmasters/answer/9008080?hl=en
Reliability: High. Google Search Console Help.

## Practice from this source
- Several people can verify the same property, with the same or different methods. Do not overwrite another owner's token.
- Verification lasts while the token stays valid. Search Console checks the token periodically and notifies if it fails.
- "If all verified owners lose access to a property, all users will lose access to the Search Console property."
- "Data is collected for a property as soon as anyone adds it in Search Console, even before verification occurs."
- A new owner can "unverify previous owners by removing their verification token" (for example, remove the HTML tag).
- Removing an HTML verification file "will cause you to lose verification for the site."
- A Domain property needs DNS verification (TXT or CNAME). Keep the DNS record after verification.
- Site Kit for WordPress can verify. Google says it is the only plugin it officially sponsors.

## Use for client-access-lockout
- B: The client can lock the agency out fully by removing tokens (HTML file, meta tag, DNS record, plugin). Ask the client which method she used before you plan the next step.
- B/D: The performance history stays with the property. A re-invited agency sees the full history again. Nothing is lost by the removal.
- D: Before the next incident, keep a list of which verification tokens belong to whom.

## Limits
- No guidance on agency-client conflict. Purely technical.
