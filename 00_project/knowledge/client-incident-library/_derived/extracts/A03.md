# A03 How a Coordinated Backlink Spam Attack Works — and How to Shut It Down
Source: articles/A03-blitzmetrics-coordinated-backlink-spam-attack.md, ARTICLE, published 2026-07-19, Dennis Yu / BlitzMetrics, https://blitzmetrics.com/how-a-coordinated-backlink-spam-attack-works/
Reliability: Medium-high. Practitioner case with dated data from his own site. Sells audits at the end.

## Practice from this source
- Sort spam into three buckets: background noise, link sellers advertising themselves, coordinated attack.
- Link-seller domains carry the sales pitch in the name (for example "buy-quality-backlinks"). They drop links "hoping you will panic and buy their cleanup service". "Do not buy anything."
- A 2026 network used disposable .store and .shop domains with keyword-stuffed names, one link each, several per day (99 domains from 2026-06-21 to 2026-07-19).
- The same domains hit several sites of the same owner. Overlap shows one operator working from a list.
- Several spam domains show inflated third-party scores (DR in the 30s) so they look respectable in tools.
- Through the whole burst, organic traffic did not drop.
- Four-question test: sudden burst? fresh keyword-stuffed domains? same domains on several properties? clear start date?
- Monitoring: sort referring domains by first-seen date, check Search Console for a manual action, watch for a real, sustained traffic drop.
- Disavow only for a confirmed manual penalty, a history of paid links, or a concentrated pattern where you are unsure.
- Use the event to harden the site: review admin accounts, 2FA, updates, malware scanner.

## Use for client-access-lockout
- A/C: Use the four-question test on the client's list (seozira.shop, backlinker.shop, googleseoexperts.shop look like this .shop pattern). Check first-seen dates against the agency's work log.
- G: Link-seller and "cleanup" vendors profit from fear. Explain this neutrally.
- D: A dated export by first-seen date shows when the links appeared, independent of the agency.

## Limits
- One site owner's experience. Does not prove that no site is ever harmed.
