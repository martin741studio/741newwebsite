# O04 Search Console Help: Links report
Source: official-docs/gsc-links-report.md, OFFICIAL, living page fetched 2026-10-12, https://support.google.com/webmasters/answer/9049606?hl=en
Reliability: High. Google Search Console Help.

## Practice from this source
- The report shows "a sample" of links. It is not a full list. Tables stop at 1,000 rows.
- Links are grouped by root domain. Duplicates are combined.
- The report keeps links found "over time". Some may no longer exist. It does not say if a link is nofollow.
- Use "Top linking sites" to "confirm that you recognize the sites listed".
- For unknown spammy sites, Google says you "might need to ask to be removed or, if all else fails, disavow them".
- The data can be exported (export button), as input for checks or a disavow list.

## Use for client-access-lockout
- A: Compare the third-party "spam domain" list with Top linking sites in Search Console. Note which domains Google itself lists.
- D: Export the Links report with a date. It is Google's own data, not a tool score.

## Limits
- "Might need to ... disavow" is softer here than on the disavow page (O02). The disavow page sets the stricter condition: manual action or likely manual action.
