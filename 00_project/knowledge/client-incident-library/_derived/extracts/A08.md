# A08 Google September 2026 Spam Update: How to Tell If You Were Hit
Source: articles/A08-witscode-september-2026-spam-update.md, ARTICLE, published 2026-10-02, Sudhakaran / WitsCode, https://witscode.com/blogs/google-september-2026-spam-update
Reliability: Medium-high. Well-sourced summary of Google's dashboard and Search Console docs. Agency blog.

## Practice from this source
- The September 2026 spam update started 2026-09-24, global, "may take up to two weeks". Google called it "a normal spam update".
- 2026 spam updates: March 24, June 24, August 18, September 24. Core updates: March 27, May 21. No September core update.
- "Any post that says this update targets X without quoting Google is guessing."
- Google's spam policies page was last updated 2026-08-28 and lists 16 policies.
- Check order in Search Console: Manual actions (green check), Security issues, daily Performance step-down date, compare periods (3 months, 16 months), split by search type, which pages lost, query demand in Google Trends.
- Do not make big changes while a rollout runs. Algorithmic recovery takes months.

## Use for client-access-lockout
- A: If the client saw a drop, match the date with the 2026 update list before any link theory.
- D: The step-down date from Performance data is objective evidence for the timeline.

## Limits
- Says nothing about links as a cause of the September update. Practitioner reports of "waves" are not confirmed by Google.
