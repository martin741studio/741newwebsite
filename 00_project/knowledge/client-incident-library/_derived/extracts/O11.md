# O11 Google Analytics Help: Add, edit, and delete users and user groups
Source: official-docs/ga4-access-management.md, OFFICIAL, living page fetched 2026-10-12, https://support.google.com/analytics/answer/9305788?hl=en
Reliability: High. Google Analytics Help.

## Practice from this source
- Users can be added at account level or property level. Account level access flows down to all properties.
- Only users with the Administrator role can add or change users. Deleting users needs Administrator at account level.
- The last Administrator cannot delete himself. This protects against a lock-out.
- Removing a user from a source property also removes the user from its subproperties.
- Users are identified by their Google Account email.

## Use for client-access-lockout
- B: The client should be Administrator at account level. The agency gets property-level Editor or Analyst access as needed.
- H: In a handover, the agency removes itself or the client removes it. Data stays in the property.

## Limits
- No guidance on agency relationships.
