# O09 Google Ads Help: Link an account to a manager account
Source: official-docs/google-ads-link-manager-account.md, OFFICIAL, living page fetched 2026-10-12, https://support.google.com/google-ads/answer/7459601?hl=en
Reliability: High. Google Ads Help.

## Practice from this source
- An agency links an existing client account to its manager account by sending a link request with the client's Customer ID.
- The client accepts or declines under Admin > Access and security > Managers.
- Only users with administrative access to the invited account receive and handle link requests.
- An agency can withdraw a sent link request.
- Accounts created from inside a manager account are linked automatically.

## Use for client-access-lockout
- B: The clean set-up is: client creates the account, agency sends a link request, client accepts. The client keeps control.
- H: In a separation, the client (admin) unlinks the manager account. No transfer is needed if the client created the account.

## Limits
- The page does not explain ownership transfer or disputes. See O10 and A09.
