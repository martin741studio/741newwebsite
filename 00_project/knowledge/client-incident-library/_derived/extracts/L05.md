# L05 BGB § 296 Entbehrlichkeit des Angebots
Source: official-docs/law-bgb-296.md, LAW, gesetze-im-internet.de, fetched 2026-10-12, https://www.gesetze-im-internet.de/bgb/__296.html
Reliability: High (statute text). Background only, not legal advice.

## Practice from this source
- If a calendar date is set for the creditor's action, no offer is needed unless the creditor acts in time.

## Use for client-access-lockout
- E: Contracts that set fixed dates for client cooperation (for example "access within 5 working days") make the position clearer. Use this for future contracts.

## Limits
- Rarely applies to an ad-hoc lock-out without a contract date.
