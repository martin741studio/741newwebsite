# A04 How to Disavow Backlinks Found in Ahrefs (540 Spam Domains)
Source: articles/A04-pelton-540-spam-domains-disavow.md, ARTICLE, published 2026-09-01 (update October 2026), Nathan Pelton, https://www.nathanpelton.com/content/blog/seo/spam-backlinks-and-the-disavow-file.htm
Reliability: High for mechanics (first-hand, six sites, dated). Medium for ranking claims (one owner).

## Practice from this source
- The author never bought links. Still 540 of 559 referring domains on one site were spam, arriving in a burst from May 2026.
- Pattern: machine-generated names on .shop, .store, .site (for example "seoexpress-verified-high-da-consultants.store"), scraper directories, expired-domain marketplaces. "seotira.com" appears as a link-seller domain.
- "None of this was aimed at me. It is a blast." The same network hit all six of his sites.
- Ahrefs Domain Rating fell from 32 to 21. DR is Ahrefs' metric, not Google's. "DR is not a ranking factor."
- Tool spam flags make errors both ways. Combine tool flag and own check, then apply a hand-kept whitelist (own sites, own YouTube channel, real partners).
- "The upload replaces the entire list. It is not a delta." Always upload the complete file. Keep a master copy.
- There is no API for disavow. Upload by hand. Domain properties are not supported; use a URL-prefix property.
- He disavowed as "cheap insurance" and as a record of intent. "It is not the fix."
- New waves came in September 2026 (607 new spam domains on one site). The file only grows.

## Use for client-access-lockout
- A/G: A wave of .shop/.store spam links in 2026 hit sites whose owners never bought links. The client's list fits this pattern.
- C: If a disavow file is ever made, keep a master copy and a whitelist. Never upload a partial list.
- F: A fall in a third-party score (DR/DA) is not a Google penalty. Say this plainly.

## Limits
- He chose to disavow. That is his judgement, not Google's requirement (see O02).
