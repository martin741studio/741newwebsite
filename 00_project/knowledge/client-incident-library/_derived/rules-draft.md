# 741 Incident-Raster — DRAFT rules for client-access-lockout

Status: DRAFT, 2026-10-12. Built from the sources in this library only. Not reviewed by Martin. Not legal advice (group E is background for a talk with a lawyer).

Format: `IF situation THEN action. Why. Src: <file>`. Authority tag per rule: [OFFICIAL] Google help or Search Central, [LAW] gesetze-im-internet.de, [ARTICLE] blog or article published 2026-07-12 or later, [VIDEO] YouTube upload 2026-07-12 or later. The tag names the strongest source of the rule. File paths are relative to this library. Short IDs in brackets (O05, L04, V08) point to `_derived/extracts/<ID>.md`.

Internal document. Never name YouTube channels, authors or tools from this library in client material. Call it "741-Bewertungsraster" outside.

Order of use in a real case: A (verify) and D (secure evidence) first, then B and C (technical facts), then F (talk), with E (contract position) in the background, G when a competitor report is involved, H for the end decision.

## A. Verification of claims

- A1 [OFFICIAL] IF a client or a third party says "your site has toxic or spam backlinks" THEN open the Search Console Manual actions report first and take a dated screenshot. Why: Google reports link penalties there; a green check mark means no manual action. Src: official-docs/gsc-manual-actions-report.md (O05)
- A2 [OFFICIAL] IF the claim is based on a third-party audit tool THEN check each recommendation against official Google documentation before any change. Why: Google tells site owners to do exactly this with third-party audits. Src: official-docs/search-central-do-you-need-an-seo.md (O07)
- A3 [OFFICIAL] IF you get a list of "spam domains" THEN compare it with Search Console > Links > Top linking sites and export that report with a date. Why: the Links report is Google's own sample of links, with no tool scores. Src: official-docs/gsc-links-report.md (O04); videos/V14-google-search-console-tutorial-2026-the-complete-guide.md
- A4 [OFFICIAL] IF you check a flagged link THEN ask one question: did the agency or the client create or buy it? Why: Google defines link spam by purpose ("creating links ... to manipulate rankings") and names bought, exchanged and automated links. Src: official-docs/search-central-spam-policies.md (O06)
- A5 [OFFICIAL] IF the check shows the agency did build questionable links (paid, automated, low-quality directories) THEN say so plainly and plan removal. Why: Google names "an SEO that you've hired" as a typical source of bad links; this is the one case where links really count against the site. Src: official-docs/gsc-disavow-links.md (O02); articles/A06-saasylinks-negative-seo-what-google-ignores.md (white-label PBN case)
- A6 [ARTICLE] IF the flagged domains are keyword-stuffed names on .shop, .store, .site or similar, one link each, arriving in a burst THEN classify them as a mass spam network, not as targeted work. Why: 2026 case data show the same networks hit many unrelated sites whose owners never bought links. Src: articles/A04-pelton-540-spam-domains-disavow.md, articles/A03-blitzmetrics-coordinated-backlink-spam-attack.md, articles/A02-suffdigital-spammy-backlinks-88-percent-small-business.md
- A7 [ARTICLE] IF you need to show who placed links THEN sort referring domains by "first seen" date and lay the dates next to the agency's work log. Why: a burst with a clear start date, unrelated to any agency task, points to an outside network. Src: articles/A03-blitzmetrics-coordinated-backlink-spam-attack.md; articles/A04-pelton-540-spam-domains-disavow.md
- A8 [ARTICLE] IF the audit cites a drop in Domain Rating or Domain Authority THEN state that these are third-party metrics, not Google signals. Why: DR/DA are tool metrics; a tool can devalue spam inside its own index and the score falls without any Google effect. Src: articles/A04-pelton-540-spam-domains-disavow.md; videos/V12-you-don-t-need-1-000-backlinks-to-rank-on-google.md
- A9 [ARTICLE] IF the client reports a ranking or traffic drop THEN check in this order: Google update dates, technical errors, Security issues, Manual actions; stop at the first yes. Why: most drops blamed on "negative SEO" have other causes. Src: articles/A06-saasylinks-negative-seo-what-google-ignores.md; articles/A08-witscode-september-2026-spam-update.md; articles/A01-ser-google-says-disavow-tool-does-have-effects.md (Mueller: look for spam update and big technical issues)
- A10 [ARTICLE] IF a drop date is near 2026-03-24, 2026-06-24, 2026-08-18 or 2026-09-24 (spam updates) or 2026-03-27, 2026-05-21 (core updates) THEN compare the step-down date in Search Console Performance with the update dates before any link theory. Why: update timing explains many drops; spam updates in 2026 were not described by Google as link updates. Src: articles/A08-witscode-september-2026-spam-update.md; videos/V09-google-september-2026-spam-update-is-here.md; videos/V10-important-change-to-seo-new-google-spam-update.md; videos/V11-google-s-august-2026-spam-update-what-businesses-need-to-kno.md
- A11 [ARTICLE] IF you check for a real attack THEN run a "site:domain" search with spam words (casino, loan, viagra) and check the Security issues report. Why: hacked or injected pages are a real risk; spam links from strangers are not. Src: articles/A06-saasylinks-negative-seo-what-google-ignores.md; articles/A03-blitzmetrics-coordinated-backlink-spam-attack.md (harden admin accounts, 2FA)
- A12 [VIDEO] IF you answer a claim THEN check the facts before you reply ("let me check the details"). Why: a guessed answer that proves wrong costs more trust than a short delay. Src: videos/V03-how-to-deal-with-difficult-business-clients-in-english.md; videos/V06-10-years-of-building-an-agency-the-lessons-nobody-sees.md (do not trust AI or tool output without a manual check)

## B. Account ownership and access (Google tools)

- B1 [OFFICIAL] IF the client removes the agency from Search Console THEN accept it as her right as owner. Do not argue about the step itself. Why: only owners manage users; removal takes effect "very quickly". Src: official-docs/gsc-managing-owners-users-permissions.md (O01)
- B2 [OFFICIAL] IF the agency still has a verification token on the site (HTML file, meta tag, DNS record) after removal THEN do not re-verify without the client's written consent, and tell her the token exists. Why: re-verification is technically possible, but all owners are notified and it overrides her decision. Src: official-docs/gsc-managing-owners-users-permissions.md (O01); official-docs/gsc-verify-site-ownership.md (O03); official-docs/law-bgb-241.md (L01, duty of consideration)
- B3 [OFFICIAL] IF the client asks what she loses by the removal THEN explain that Search Console data belongs to the property and keeps being collected; a re-invited user sees the full history again. Why: data is collected per property, not per user. Src: official-docs/gsc-verify-site-ownership.md (O03); official-docs/gsc-managing-owners-users-permissions.md (O01)
- B4 [OFFICIAL] IF access is to be restored THEN ask the client to add the agency's Google Account as Full user (or Owner if disavow or ownership tasks are in scope) under Settings > Users and permissions. Why: full users can use most tools; only owners manage users and (per the disavow page) upload disavow files. Src: official-docs/gsc-managing-owners-users-permissions.md (O01); official-docs/gsc-disavow-links.md (O02)
- B5 [OFFICIAL] IF you set up or review any client account THEN the client holds the top role: Search Console verified owner, Business Profile primary owner, Google Ads admin, GA4 account administrator, Tag Manager account administrator. The agency gets a working role. Why: each Google help page puts user control at the top role only; Tag Manager help says the account should be managed by someone in the organization, "not an external agency". Src: official-docs/gsc-managing-owners-users-permissions.md (O01); official-docs/gbp-manage-owners-managers.md (O08); official-docs/google-ads-access-levels.md (O10); official-docs/ga4-access-management.md (O11); official-docs/gtm-user-permissions.md (O12)
- B6 [OFFICIAL] IF the agency works on a Business Profile THEN use Manager access, not Owner. Why: managers can do nearly all daily work; owners control users and deletion. Src: official-docs/gbp-manage-owners-managers.md (O08); articles/A10-searchpod-who-should-own-gbp.md; articles/A11-leadsie-gbp-access.md; articles/A12-clientomic-gbp-edit-access.md
- B7 [OFFICIAL] IF the agency runs Google Ads THEN the client creates the account and the agency links its manager account. Why: an account created inside the agency's manager account makes the agency owner; only Admin can unlink managers. Src: official-docs/google-ads-link-manager-account.md (O09); official-docs/google-ads-access-levels.md (O10); articles/A09-kampaio-google-ads-agency-account-ownership.md
- B8 [ARTICLE] IF there is any conflict THEN never use access to accounts or data as a bargaining chip (for example against an open invoice). Why: most ownership disputes are about access used as leverage in billing fights; it destroys trust and Google support does not arbitrate contracts. Src: articles/A09-kampaio-google-ads-agency-account-ownership.md
- B9 [OFFICIAL] IF the client is unsure who has access THEN offer a joint access review: list every owner, user and pending invite with the reason for access. Why: Google says an unknown owner may mean a hack; a clear list removes fear. Src: official-docs/gsc-managing-owners-users-permissions.md (O01) ("Don't recognize an owner?"); articles/A12-clientomic-gbp-edit-access.md (six-step access check)
- B10 [OFFICIAL] IF an outside party wants to audit the client's site THEN recommend read-only access (Restricted user) for them. Why: Google advises site owners to grant only read access for an audit. Src: official-docs/search-central-do-you-need-an-seo.md (O07)

## C. Disavow and spam links

- C1 [OFFICIAL] IF there is no manual action and no own link scheme THEN do not recommend a disavow file. Why: Google says most sites do not need it, and wrong use can harm performance. Src: official-docs/gsc-disavow-links.md (O02); articles/A05-auspia-how-to-disavow-2026.md (gate table); articles/A02-suffdigital-spammy-backlinks-88-percent-small-business.md
- C2 [OFFICIAL] IF anyone plans a disavow upload THEN first record the current list (summary on the tool page, saved master file). Why: a new upload replaces the existing list completely. Src: official-docs/gsc-disavow-links.md (O02); articles/A04-pelton-540-spam-domains-disavow.md; articles/A05-auspia-how-to-disavow-2026.md
- C3 [OFFICIAL] IF the agency has no owner access THEN state in writing that it cannot have uploaded, changed or removed any disavow file after the removal date. Why: only property owners can upload a disavow list. Src: official-docs/gsc-disavow-links.md (O02); official-docs/gsc-managing-owners-users-permissions.md (O01)
- C4 [ARTICLE] IF a disavow file is really needed (manual action, or a large spam flood where the client wants insurance) THEN build it from the Search Console Links export plus a manual check, with a whitelist of real links, `#` comment lines with date and reason, and upload the complete file each time. Why: tool "toxic" flags err both ways, uploads are not additive, and comments are the only audit trail inside the tool. Src: articles/A04-pelton-540-spam-domains-disavow.md; articles/A05-auspia-how-to-disavow-2026.md; official-docs/gsc-disavow-links.md (O02)
- C5 [OFFICIAL] IF a manual action for unnatural links exists THEN first try to remove links and log each attempt, then disavow the rest, then request review with documentation. Why: Google says blind disavowing "is not considered a good-faith effort". Src: official-docs/gsc-manual-actions-report.md (O05)
- C6 [ARTICLE] IF a disavow file exists and rankings fell THEN check whether the file is right ("might be empty, or might not be empty") and look for other causes before changing it again. Why: the tool "does have effects"; a handful of links will not drop a site, and recovery from updates can take months. Src: articles/A01-ser-google-says-disavow-tool-does-have-effects.md
- C7 [OFFICIAL] IF the property is a Domain property THEN note that the disavow tool needs a URL-prefix property. Why: the tool does not support Domain properties. Src: official-docs/gsc-disavow-links.md (O02); articles/A04-pelton-540-spam-domains-disavow.md; articles/A05-auspia-how-to-disavow-2026.md
- C8 [ARTICLE] IF you judge the effect of a disavow upload THEN wait weeks to months; do not judge after days. Why: Google needs "a few weeks" to process; disavowed links still show in the Links report. Src: official-docs/gsc-disavow-links.md (O02); articles/A05-auspia-how-to-disavow-2026.md

## D. Evidence and documentation

- D1 [OFFICIAL] IF a claim or a lock-out starts THEN take dated screenshots and exports before you change anything: Manual actions, Security issues, Links report (Top linking sites), Performance (16 months), Users and permissions, disavow tool summary. Why: Google's own reports are neutral evidence; access can disappear at any time. Src: official-docs/gsc-manual-actions-report.md (O05); official-docs/gsc-links-report.md (O04); articles/A12-clientomic-gbp-edit-access.md ("record it before changing access"); videos/V14-google-search-console-tutorial-2026-the-complete-guide.md
- D2 [ARTICLE] IF you document an incident THEN record the exact item, the wording, the date you noticed it, and the source record, without guessing who caused it. Why: "Start with evidence, not an accusation" gives a clean timeline. Src: articles/A12-clientomic-gbp-edit-access.md
- D3 [ARTICLE] IF the client asks what the agency did THEN send a list of measures with dates, and for links a link document (target page, linking page, date, how the link came about). Why: a written handover document, not a call note, is the standard proof; Google tells owners to expect a full change log. Src: articles/A30-dama-seo-agentur-wechseln-uebergabe.md; official-docs/search-central-do-you-need-an-seo.md (O07)
- D4 [ARTICLE] IF you run any client program THEN keep one status record per project (stage, owner, next action, date at risk), log every change request in writing, and log time daily. Why: status spread over many places and week-old time entries are not evidence. Src: articles/A36-productive-agency-project-management-guide.md
- D5 [ARTICLE] IF technical work is invisible to the client THEN send a short fixed-rhythm update (what shipped, what is next, what we need from you, did the date move). Why: without updates clients assume nothing happens, and a third-party audit lands harder. Src: articles/A36-productive-agency-project-management-guide.md; articles/A33-sel-seo-client-onboarding-first-90-days.md
- D6 [ARTICLE] IF you start with a new client THEN send the kickoff notes and the split of responsibilities (including who gives access) for written confirmation. Why: friction comes from "assumptions about who owns what"; confirmed notes prove the agreed scope. Src: articles/A33-sel-seo-client-onboarding-first-90-days.md
- D7 [VIDEO] IF you prove results THEN use Search Console compare mode (for example 16 months, non-branded queries via regex filter). Why: it shows growth "with Google's own data behind it". Src: videos/V14-google-search-console-tutorial-2026-the-complete-guide.md
- D8 [ARTICLE] IF disavow or link removal work is ever done THEN keep the master file with `#` comment lines (date, reason) and a removal log (URL, contact, date, result). Why: the tool keeps no history, and Google asks for documentation in reconsideration. Src: articles/A05-auspia-how-to-disavow-2026.md; articles/A04-pelton-540-spam-domains-disavow.md; official-docs/gsc-manual-actions-report.md (O05)
- D9 [LAW] IF you send the client a status, offer or deadline THEN send it in writing (email with date, or registered letter for notice) and keep a copy. Why: the written offer and the request to restore access are legally relevant; notice needs proof of receipt. Src: official-docs/law-bgb-295.md (L04); articles/A30-dama-seo-agentur-wechseln-uebergabe.md
- D10 [VIDEO] IF the error is real THEN do an internal review first: what did we do wrong, what did the client do wrong. Why: failure is often two-sided; the review prevents a defensive call. Src: videos/V06-10-years-of-building-an-agency-the-lessons-nobody-sees.md

## E. Contract, cooperation duty and pausing work (German law, background only)

Not legal advice. Use these rules to prepare a talk with a lawyer, not to replace it.

- E1 [LAW] IF you must judge the legal position THEN first decide the contract type from the agreed work: activities without a promised result point to a service contract (Dienstvertrag, § 611 BGB); a defined result points to a contract for work (Werkvertrag, § 631 BGB). Why: pay, cooperation and termination rules differ by type. Src: official-docs/law-bgb-611.md (L07); official-docs/law-bgb-631.md (L12); articles/A23-anwaltde-6000-euro-werbung-agentur-rechnung.md; articles/A22-anwaltde-internet-system-vertrag-48-monate-kuendigen.md
- E2 [ARTICLE] IF the program contains defined deliverables (pages, website, set-up) THEN expect a court to treat those parts as Werkvertrag; the client can then end them at any time and the agency keeps pay only for done work minus savings. Why: BGH classes "Internet-System-Verträge" as Werkvertrag; § 648 BGB gives free termination. Src: articles/A22-anwaltde-internet-system-vertrag-48-monate-kuendigen.md; official-docs/law-bgb-648.md (L15)
- E3 [LAW] IF the client blocks access that the agreed work needs THEN send a dated written message that offers the agreed work and asks her to restore access. Why: under § 295 BGB a written offer is enough when the work needs an action of the client, and the request to do that action counts as the offer; this can start Annahmeverzug (§ 293). Src: official-docs/law-bgb-295.md (L04); official-docs/law-bgb-293.md (L02)
- E4 [LAW] IF the client is in Annahmeverzug under a service contract THEN note that the agency may keep its claim to the agreed fee for the blocked period without later performance, minus savings and other earnings. Do not lead with this in client talks. Why: § 615 BGB. Src: official-docs/law-bgb-615.md (L08)
- E5 [LAW] IF Werkvertrag parts need the client's action and she does not act THEN the agency can set a reasonable deadline with the statement that the contract ends if the action is not done; only with legal advice. Why: §§ 642, 643 BGB give compensation and a deadline-based termination. Src: official-docs/law-bgb-642.md (L13); official-docs/law-bgb-643.md (L14)
- E6 [LAW] IF anyone considers termination for an important reason THEN set a written deadline to remedy or a warning first, and act within the legal time limit (two weeks from knowledge under § 626). Why: §§ 314 and 626 BGB require this in most cases. Src: official-docs/law-bgb-314.md (L06); official-docs/law-bgb-626.md (L10)
- E7 [LAW] IF the client says she can end the contract at once because SEO is a trust service THEN check the contract for a § 627 BGB clause and get legal advice. Why: § 627 allows termination at any time for "Dienste höherer Art" based on special trust, unless a fixed-pay permanent relationship exists; client lawyers use this argument. Src: official-docs/law-bgb-627.md (L11); articles/A23-anwaltde-6000-euro-werbung-agentur-rechnung.md
- E8 [ARTICLE] IF the client side asks for proof of work THEN provide dated evidence per month (changed URLs, reports, posts, emails). Why: client lawyers dispute agency invoices first by asking for proof of work. Src: articles/A23-anwaltde-6000-euro-werbung-agentur-rechnung.md; articles/A25-avervo-agenturvertrag-kuendigen-pruefen.md
- E9 [ARTICLE] IF a client is disappointed with results THEN separate agreed work, delivered work and result in the discussion. Why: weak results alone are not poor work and are not automatically a ground for immediate termination. Src: articles/A25-avervo-agenturvertrag-kuendigen-pruefen.md
- E10 [ARTICLE] IF you write offers, contracts and sales talk THEN do not promise rankings or "top placement"; state term and total price in figures; name the client's cooperation duties (access, approvals) and the consequence of a client-side stop. Why: success promises push the contract toward Werkvertrag rules; unclear price or term clauses fail in AGB review. Src: articles/A22-anwaltde-internet-system-vertrag-48-monate-kuendigen.md; articles/A23-anwaltde-6000-euro-werbung-agentur-rechnung.md; official-docs/law-bgb-296.md (L05, calendar-dated cooperation)
- E11 [LAW] IF the agency itself wants to end the relationship THEN give notice in a way that lets the client get the services elsewhere (no termination at an unsuitable time without good reason), and check the statutory notice periods. Why: § 627 (2) and § 621 BGB. Src: official-docs/law-bgb-627.md (L11); official-docs/law-bgb-621.md (L09)
- E12 [LAW] IF the conflict grows THEN still protect the client's rights and interests (no harm to her site, no withholding of her data). Why: the duty of consideration binds both parties during the contract. Src: official-docs/law-bgb-241.md (L01); articles/A25-avervo-agenturvertrag-kuendigen-pruefen.md (lawyer when data is withheld)

## F. Communication with a mistrustful client

- F1 [VIDEO] IF the client is scared or angry THEN start with empathy and no defence: "I understand this worried you." Then the solution. Why: "Empathy first, solution second"; an early defence escalates. Src: videos/V02-how-to-deal-with-difficult-clients-in-english.md
- F2 [VIDEO] IF you write the first message THEN put topic, what you want her to do, and the main point in the first three sentences; details after. Why: readers lose attention if they do not know what the message wants ("bottom line up front"). Src: videos/V01-how-to-start-any-conversation-the-right-way-chris-fenning.md
- F3 [VIDEO] IF a claim is false THEN correct it with records, not with "you are wrong": "According to our records the situation is different. Here is the data." Why: neutral sources (records, agreement, Google reports) move the talk to facts. Src: videos/V03-how-to-deal-with-difficult-business-clients-in-english.md; videos/V02-how-to-deal-with-difficult-clients-in-english.md ("numbers are neutral")
- F4 [VIDEO] IF the check finds a real agency mistake THEN admit it in the first person, name the impact, give the fix and what changes. No "sorry, but". Why: a specific apology rebuilds trust; vague apologies do not. Src: videos/V04-how-to-apologize.md; videos/V03-how-to-deal-with-difficult-business-clients-in-english.md; articles/A32-mailbird-professional-apology-email-client.md; videos/V17-this-is-why-car-mechanics-lose-customer-trust.md
- F5 [ARTICLE] IF you apologize THEN apologize only for what you checked and confirmed; keep the cause to one line. Why: over-apologizing for unconfirmed claims invites blame; "long backstories sound defensive". Src: articles/A32-mailbird-professional-apology-email-client.md
- F6 [ARTICLE] IF the issue involves access or reputation risk THEN call first, then send a written recap the same day (thanks, what we agreed, next step with a date). Why: calls lower the heat; the recap is the record. Src: articles/A32-mailbird-professional-apology-email-client.md; videos/V02-how-to-deal-with-difficult-clients-in-english.md
- F7 [VIDEO] IF you promise a next step THEN give a specific date or time and one contact person. Why: "soon" and "I'll see what I can do" weaken trust. Src: videos/V02-how-to-deal-with-difficult-clients-in-english.md; videos/V03-how-to-deal-with-difficult-business-clients-in-english.md; articles/A32-mailbird-professional-apology-email-client.md
- F8 [VIDEO] IF the client never saw the agency's work THEN do not lecture; show three to five dated facts. Why: invisible work creates doubt; a short evidence list replaces "please trust me". Src: videos/V08-how-i-use-a-free-5-minute-audit-to-get-agency-clients-no-sal.md ("just look at this"); articles/A33-sel-seo-client-onboarding-first-90-days.md
- F9 [VIDEO] IF the client reports a problem THEN never dismiss it ("everything is fine"). Check it and show the result. Why: dismissing a real complaint is what breaks trust for good. Src: videos/V17-this-is-why-car-mechanics-lose-customer-trust.md; videos/V03-how-to-deal-with-difficult-business-clients-in-english.md
- F10 [OFFICIAL] IF you explain the client's risk THEN acknowledge that her concern is reasonable: Google tells site owners they are responsible for what their SEO does. Why: it validates her fear without accepting false claims. Src: official-docs/search-central-do-you-need-an-seo.md (O07)
- F11 [VIDEO] IF you must say that blocked access stops the work THEN say the limit first and the alternative right after ("Without access we cannot do X. We can do Y now, or continue as soon as access is back."). Why: "Boundary first, alternative second." Src: videos/V02-how-to-deal-with-difficult-clients-in-english.md
- F12 [VIDEO] IF the client is rude THEN set one calm limit and continue on the facts. Why: a short limit keeps the talk professional without escalation. Src: videos/V03-how-to-deal-with-difficult-business-clients-in-english.md
- F13 [ARTICLE] IF you suggest a second opinion THEN offer an independent check of the claims (read-only access for the reviewer). Why: an independent view settles fact questions; Google advises read access for audits. Src: articles/A30-dama-seo-agentur-wechseln-uebergabe.md; official-docs/search-central-do-you-need-an-seo.md (O07)

## G. Competitor "fake audit" poaching and scare reports

- G1 [OFFICIAL] IF the client got an unsolicited audit or SEO email THEN tell her neutrally that Google itself warns about SEO firms that "email you out of the blue" and about guaranteed rankings. Why: it is Google's own advice to site owners, not the agency defending itself. Src: official-docs/search-central-do-you-need-an-seo.md (O07)
- G2 [VIDEO] IF you explain where the scary report came from THEN describe the known sales method: a one-click tool audit, a low score, no offer in the first message, the sale after the owner asks. Why: agency trainers teach this method openly in 2026. Src: videos/V08-how-i-use-a-free-5-minute-audit-to-get-agency-clients-no-sal.md
- G3 [ARTICLE] IF the report lists link-seller domains (names like "buy-backlinks", "seo-expert", "seotira") THEN explain that these vendors drop links to appear in reports and sell "clean-up". Why: practitioners document this pattern; Google said agencies that sell both attacks and clean-up "are just making stuff up". Src: articles/A03-blitzmetrics-coordinated-backlink-spam-attack.md; articles/A06-saasylinks-negative-seo-what-google-ignores.md; articles/A04-pelton-540-spam-domains-disavow.md
- G4 [ARTICLE] IF a German agency sells "toxische Backlinks" audits with ongoing disavow work THEN compare its claims with Google's disavow page. Why: such offers exist in the German market and advise routine disavow, which Google does not support. Src: articles/A07-werbeagentur-nuernberg-toxische-backlinks.md; official-docs/gsc-disavow-links.md (O02)
- G5 [VIDEO] IF you answer the competitor report THEN do not attack the competitor. Answer with your own checkable evidence ("just look at this"). ## H. Retention vs clean separation and handover

- H1 [VIDEO] IF the client still cooperates after the facts are clear THEN fix confirmed issues at once and agree on a feedback rhythm. Why: unhappiness found early can be fixed; found at cancellation it cannot. Src: videos/V06-10-years-of-building-an-agency-the-lessons-nobody-sees.md
- H2 [ARTICLE] IF you decide whether to keep the client THEN check three causes: the agency, the expectation, or the market. Only the first is fixed by a change of agency. Why: it shows which complaint is real and what a change would solve. Src: articles/A30-dama-seo-agentur-wechseln-uebergabe.md
- H3 [VIDEO] IF the client does not accept checked facts and keeps access blocked THEN expect separation as one normal outcome and prepare it calmly. Why: some clients do not accept hard truths; results without cooperation fail. Src: videos/V06-10-years-of-building-an-agency-the-lessons-nobody-sees.md; articles/A35-wunderlandmedia-signs-fire-a-client.md
- H4 [ARTICLE] IF you part ways THEN keep the exit message short: end date, promise of a smooth handover, no blame, no long justification. Why: long messages read like apologies and invite negotiation. Src: articles/A35-wunderlandmedia-signs-fire-a-client.md; articles/A30-dama-seo-agentur-wechseln-uebergabe.md
- H5 [ARTICLE] IF you part ways THEN start from the contract (end date, notice, scope, fees, data duties), name one offboarding owner, and send a dated schedule within two business days. Why: a contract-based plan keeps emotion out. Src: articles/A31-chaser-client-offboarding-checklist-agencies.md; official-docs/law-bgb-621.md (L09)
- H6 [ARTICLE] IF you hand over THEN deliver one written document: measures with dates, open tasks, redirect list, content pipeline, access overview, last report with raw-data export. Why: oral handovers get lost; the document is also the agency's proof. Src: articles/A30-dama-seo-agentur-wechseln-uebergabe.md; articles/A31-chaser-client-offboarding-checklist-agencies.md
- H7 [ARTICLE] IF you leave any client account THEN confirm first that the client holds admin or owner access and recovery details, then remove the agency user and keep proof of each removal, including tokens. Why: removing a visible user can leave tokens active; the client must not be locked out. Src: articles/A31-chaser-client-offboarding-checklist-agencies.md; official-docs/gsc-managing-owners-users-permissions.md (O01); official-docs/gbp-manage-owners-managers.md (O08)
- H8 [ARTICLE] IF an invoice is open THEN do not withhold client data or access. Why: using access as leverage is the main source of disputes; withholding files without legal advice is "an unsupported threat". Src: articles/A31-chaser-client-offboarding-checklist-agencies.md; articles/A09-kampaio-google-ads-agency-account-ownership.md
- H9 [ARTICLE] IF the separation is final THEN advise the client: delete nothing, keep all redirects, and agree who handles outages in the transition weeks. Why: deleted pages lose positions. Src: articles/A30-dama-seo-agentur-wechseln-uebergabe.md
- H10 [VIDEO] IF honesty costs revenue (for example "you do not need a disavow" or "you do not need this service") THEN still say it. Why: honest advice that loses a job keeps trust and reputation. Src: videos/V17-this-is-why-car-mechanics-lose-customer-trust.md; official-docs/gsc-disavow-links.md (O02)
- H11 [ARTICLE] IF the separation is done THEN hold an internal review and feed lessons into scoping, access set-up and contracts. Why: closes the loop and prevents the next incident. Src: articles/A31-chaser-client-offboarding-checklist-agencies.md
