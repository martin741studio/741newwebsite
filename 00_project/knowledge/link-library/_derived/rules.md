## B. Lokaler Linkaufbau (Src: 020 — Ahrefs "Link Building for Local SEO: 6 Easy Ways")

- RB.1 IF ein Link bewertet wird THEN zähle Kontext-Relevanz UND Orts-Relevanz UND Autorität getrennt — nicht nur DR. Ein Link kann lokal stark sein, aber inhaltlich schwach ("glorified citation"), oder umgekehrt. Src: 020
- RB.2 IF lokale Linkaufbau geplant wird THEN rechne mit weniger Konkurrenz als im globalen Linkaufbau, aber auch mit weniger verfügbaren Zielen — mehr Kreativität nötig, nicht mehr Volumen. Src: 020
- RB.3 IF eine Handelskammer (IHK) geprüft wird THEN zuerst klären, ob die Branche überhaupt IHK-pflichtig ist. Freie Berufe (Heilpraktiker, Ärzte, Architekten) sind oft NICHT IHK-Mitglied. Src: 020 (angepasst — Video geht von US-Chamber-of-Commerce aus, DACH-Fall: IHK/HWK prüfen, nicht automatisch annehmen)
- RB.4 IF eine branchen-spezifische Berufsvereinigung existiert THEN hat sie fast immer eine Mitglieder-Verzeichnis-Seite mit Link — das ist der verlässlichste "local + authority"-Treffer. Src: 020
- RB.5 IF nach Ressourcen-Seiten gesucht wird THEN nutze `inurl:ressourcen`/`inurl:links`/`inurl:partner` + Stadt + Branche, und zusätzlich verwandte (nicht konkurrierende) lokale Branchen prüfen — Hersteller, Zulieferer, komplementäre Praxen. Src: 020
- RB.6 IF eine Ressourcen-Seite gefunden wird THEN erst prüfen, ob sie überhaupt nach außen verlinkt, bevor man anfragt. Src: 020
- RB.7 IF lokale Gastbeitrags-Ziele gesucht werden THEN nach Blogs mit echtem Content (nicht nur Kontakt-/Galerie-Seiten) in der Stadt suchen, DR-Filter 30–60 als praktikable Mitte. Src: 020
- RB.8 IF "Beste X in [Stadt]"-Listen gesucht werden THEN gezielt nach Varianten suchen ("Beste …", "Tipps für …", "… in [Stadt]") — das sind gleichzeitig Linkquelle UND Kundengewinnungs-Kanal. Pitch persönlich, kurz, mit Eigenbezug zur Liste. Src: 020
- RB.9 IF ein Hersteller/Lieferant genutzt wird (Gerät, Methode, Marke) THEN dessen "Anwender"/"Therapeutensuche"-Seite prüfen — meist die kontextuell stärkste lokale Linkquelle überhaupt, weil exakt themenpassend. Src: 020 (Tactic 3, lokal angewandt)
- RB.10 IF Vereins-/Event-Sponsoring geprüft wird THEN ist das ein "lokal stark, inhaltlich schwach"-Link (RB.1) — wertvoll für NAP/lokale Signale, aber nicht die erste Priorität vor echten Content-Links. Src: 020 (abgeleitet)

## D. Digitale PR & Outreach (Src: 009, 011, 016, 021, 025, 031, 036, 042, 043, 059, 063 — Titel/Themen, kein Volltext-Pass)

- RD.1 IF eine Outreach-Mail geschrieben wird THEN kurz, ein klarer Ask, Bezug zur Zielseite in der ersten Zeile — kein Massentext. Src: 011 (Titel: "How to Write Outreach Emails That Won't Get Ignored")
- RD.2 IF eine Seite defekte/alte Links enthält THEN das ist eine Linkchance (Broken-Link-Technik) — eigene Website UND Wettbewerber-/Ressourcenseiten auf tote Links prüfen und Ersatz anbieten. Src: 009, 016, 023, 039 (Broken Link Building Serie)
- RD.3 IF Pressemitteilungen genutzt werden THEN kostenlose DACH-PR-Portale (z. B. openPR.de, bestätigt: echte Gesundheits-PMs dort aktiv) für eigene Neuigkeiten nutzen — neues Angebot, neue Leistung, echte Zahl. Kein HARO-Äquivalent in DACH zuverlässig identifiziert — [FEHLT: dedizierte Recherche-Runde].
- RD.4 IF Linkaufbau skaliert werden soll THEN System > Einzelaktion — Tabelle/Pipeline mit Status pro Ziel führen (passt zu `client_backlinks`). Src: 025 ("Copy My Link Building System")
- RD.5 IF eine Outreach-Kampagne bewertet wird THEN echte Antwortraten sind niedrig (Case-Study-Reihe zeigt zweistellige, nicht hohe Prozentsätze) — Volumen und Nachfassen einplanen, nicht nach 5 Mails aufgeben. Src: 031, 042, 043 (Case-Study-Reihe)

## G. Wettbewerber-/Gap-Analyse (Src: 004, 017, 020 Tactic 6, 029, 033, 035, 054)

- RG.1 IF Wettbewerber-Links analysiert werden THEN Domains sammeln, die auf MEHRERE Wettbewerber verlinken, nicht nur auf einen — je mehr Wettbewerber eine Domain verlinkt, desto relevanter ist sie fürs eigene Linkprofil. Src: 020 (Tactic 6), 033, 035
- RG.2 IF Wettbewerber ausgewählt werden THEN echte Geschäfts-Konkurrenten nehmen (Map Pack + organische Top-Treffer), Verzeichnisse/Blogs aus der Liste ausschließen. Src: 020
- RG.3 IF eine Gap-Domain einen Rank-Wert nahe 0 bei gleichzeitig hoher Backlink-/Referring-Domain-Zahl hat THEN als Spam-/Linkfarmen-Verdacht behandeln, nicht verfolgen — echte Autorität und Linkvolumen korrelieren normalerweise. Src: eigene Beobachtung, bestätigt durch G-Reihe (029 "stealing from low-quality pages" warnt vor genau diesem Muster als Negativbeispiel)
- RG.4 IF der Wettbewerber-Pool klein/schwach ist (wenige Referring Domains insgesamt) THEN erwarte eine dünne, überwiegend minderwertige Gap-Liste — das ist ein valider Befund, kein Fehler der Methode. Mehr Wettbewerber (6–9 statt 5) erhöhen die Trefferzahl deutlich, auch wenn der Spam-Anteil hoch bleibt.

## H. Lokale Backlinks — Priorität und Timing (Src: 098)

- RH.1 IF Review-Geschwindigkeit auf dem GBP und On-Page-Keywords noch nicht solide sind THEN lokale Backlinks zurückstellen — sie sind der nächste Hebel danach, nicht der erste Schritt. Src: 098
- RH.2 IF der nächstgelegene Wettbewerber im Map-Grid schwach abschneidet THEN die Suche stadtweit ausweiten und den tatsächlich dominierenden Betrieb analysieren, nicht den schwachen Nachbarn. Src: 098 (ergänzt R0.2 der G-Reihe)
- RH.3 IF ein Wettbewerber-Linkprofil gezogen wird THEN die Domain über das verlinkte GBP-Profil verifizieren, nicht nur über den Firmennamen raten — und auf Redirects nach Übernahme/Fusion prüfen, bevor die Domain als eigenständige Konkurrenz gewertet wird. Src: 098
- RH.4 IF Ziele priorisiert werden THEN feste Reihenfolge, keine Mischung mit dem Score: 1. IHK/HWK (nur wenn die Branche tatsächlich pflichtig ist, siehe RB.3), 2. Branchenverband/Nischen-Verzeichnis mit Fach- UND Ortsbezug, 3. alles andere nach Nähe zur Praxis-Adresse sortiert — näher schlägt höhere Autorität. Src: 098 — **präzisiert RB.4**: bei freien Berufen ohne IHK-Pflicht rutscht der Berufsverband NICHT auf Stufe 1 hoch, er bleibt Stufe 2.
- RH.5 IF die Nähe zum Standort bewertet wird THEN das ist eine eigene, dritte Stufe — nicht gleichbedeutend mit „irgendwo in der Stadt". Eine kleine Organisation zwei Straßen weiter kann vor einer größeren, weiter entfernten stehen, weil der Map-Pack-Algorithmus selbst näheabhängig ist. Src: 098
- RH.6 IF ein Referring-Domains-Export vorliegt THEN vor dem manuellen Scoring durch den Klassifikator-Prompt laufen lassen (`_derived/local-backlink-classifier-prompt.md`) — trennt lokal/regional/national/Spam mit Belegpflicht, bevor Zeit in einzelne Domains investiert wird. Src: 098
- RH.7 IF ein Preis für Vereins-/Verband-Sponsoring verhandelt wird THEN als Richtwert 100–250 € für einen Standard-Eintrag, bis ~500 € für einen starken, dient als Plausibilitätscheck gegen die DACH-Preisbänder in Abschnitt 3.1/3.2 der Workflow-Doc. Src: 098
- RH.8 IF ein Backlink-Ergebnis an den Kunden berichtet wird THEN die ROI-Kette zeigen: Grid-Coverage-Zuwachs → geschätzte Mehr-Anrufe → Abschlussquote → Customer Lifetime Value — Umsatz und Gewinn sind unterschiedliche Zahlen, der Gewinn muss die Investition decken, nicht der Umsatz. Src: 098
