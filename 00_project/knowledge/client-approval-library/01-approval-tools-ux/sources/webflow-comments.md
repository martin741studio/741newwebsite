# Webflow Help Center: Comments

- URL: https://help.webflow.com/hc/en-us/articles/33961339882131-Comments
- Type: official help center (living doc)
- Fetched: 2026-10-13

## Key points
- Comments pin to an element on the page, at one breakpoint.
- If the element moves, the comment moves with it.
- If the element is deleted, the comment moves to the parent element.
- Each new thread stores OS, browser, viewport and device.
- Comment-only share links let people comment without an account.
- Guests enter name and email; they must verify the email.
- The browser remembers the guest on the next visit.
- Guests see preview mode only and cannot edit anything.
- Rate limits and email checks reduce spam from anonymous users.
- Threads can be resolved and reopened; resolved ones hide by default.
- Email settings: all comments, replies and mentions only, or none.
- @mentions send an email with a direct link to the thread.
- Warning: comments on a page branch are deleted when the branch merges.
- Limit: 20,000 threads per site, 50 replies per thread.
