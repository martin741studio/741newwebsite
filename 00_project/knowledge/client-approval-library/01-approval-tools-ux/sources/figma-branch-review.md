# Figma Help Center: request a branch review / review branch changes

- URLs:
  - https://help.figma.com/hc/en-us/articles/5691414603543 (Request a branch review)
  - https://help.figma.com/hc/en-us/articles/5693123873687 (Review branch changes)
- Type: official help center (living doc)
- Fetched: 2026-10-13

## Key points
- The author picks reviewers and writes a short description of the change.
- Reviewers get an in-app note and an email.
- Reviewers choose: approve the branch, or request changes.
- They can also leave comments on single layers.
- Status badges: "In review" (gray), "Changes suggested" (yellow), "Approved".
- Approval covers the whole branch. There is no partial approval.
- Review is optional. Merge rights are separate from review rights.
- Approved does not mean merged. Someone with edit rights merges it.
- After merge, the branch is archived and locked.
- "Request another review" works as a reminder or a resubmit.
