## Key points
- Compare mode shows the two latest versions side by side, with all comments.
- Overlay mode stacks versions with a fade slider to spot small visual changes.
- Text compare marks added text green and removed text red (higher plans).
- Comment sidebar works as a to-do list to check that every request was done.
- Version history shows who approved or requested changes, per version and per reviewer group.
- Clicking a status shows the exact time of each decision.
- PDF review report: all comments and decisions for one version, with timestamps.
- PDF full file report: all versions and groups, with timestamps.
- Two decisions only for reviewers: "Approve" (green) or "Request changes" (orange).
