## Key points
- New "Next Steps" tab next to comments.
- It shows who opened, who approved, who is pending, who asked for changes.
- It updates live, so the team can chase the one person still open.
- Example display: "one of two approvals".
- Shortcuts there set a feedback deadline or lock the canvas with a password.
- A scanner checks new canvases for broken links before the client sees them.
- Responsive view has device presets (iPhone, Pixel, iPad) and custom widths.
- Each comment stores the screen width it was made on.
- Clicking the comment restores that width, so both sides see the same layout.
- PDF export: one page per comment, with screenshot, replies and metadata.
- The PDF serves as a record for approvals and scope talks.
- Coming: an MCP server and CLI so AI coding tools can read comments.
