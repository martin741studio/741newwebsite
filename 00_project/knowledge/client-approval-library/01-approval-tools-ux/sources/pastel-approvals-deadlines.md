## Key points
- Clients open one link and comment. No login and no install.
- Comments sit on the live website, with screenshot and browser data.
- Only reviewers see the green "Finish Review" button. The owner does not.
- The modal offers two choices: approve, or request changes.
- A reviewer can approve without writing any comment.
- Approval is tied to a version. A new version resets all approvals.
- Owners see the approval count on the dashboard for the current version.
- The team can pause comments. The canvas is then read-only for clients.
- The team can still comment internally while it is paused.
- A feedback deadline pauses comments automatically at a set time.
- A calendar icon shows the deadline; after it, the icon says "paused".
