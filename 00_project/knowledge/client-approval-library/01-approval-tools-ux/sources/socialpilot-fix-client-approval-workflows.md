## Key points
- Attach every comment and decision to the item itself. One history, one approved draft.
- Set a fixed approval window (e.g. 48 hours) when the request goes out.
- Agree on that window during onboarding.
- Decide in advance what happens when the window closes: publish, postpone, or flag.
- Make that rule per content type.
- Auto-approve only low-risk items.
- Items with claims, prices or third-party names always need an explicit yes.
- Name one approver per client, plus a deputy for holidays.
- Use a branded approval link with no account and no password.
- Make approval fast on a phone; clients approve between other tasks.
- Check that the link still works when forwarded.
- Keep a timestamped record of each approval.
