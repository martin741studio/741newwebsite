# Filestage: favorite automations

- Type: official help center (living doc, no date shown)
- Fetched: 2026-10-13

## Key points
- "Add a due date": when a review starts, set a due date N days ahead (example: 2 days).
- The due-date rule can live in a project template, so nobody forgets it.
- "Next reviewer group": when group 1 approves, the file moves to group 2 automatically.
- "Move to section": when the final group approves, the file moves to "Ready for publishing".
- Optional: a Zapier step pushes files from that section to a CMS.
- "Specific reviewer": one key person's decision can change status and skip ahead.
- "Archive": projects with no activity for a set time (e.g. 90 days) get archived.
- Zapier offers a trigger when a review due date arrives.
