# How to Move a Google Business Profile to Another State or New Location (Sterling Sky)

- URL: https://www.sterlingsky.ca/how-to-move-google-business-profile-across-state-lines/
- Published: 2026-09-29 (modified 2026-09-30), Elizabeth Rule
- Fetch date: 2026-10-13

## Key points

- Google requires re-verification when a verified business moves to a new address.
- Proximity is a major local factor. Rankings near the old address will drop and rankings near the new address can rise.
- The local competitors change with the move. Old rankings are not a fair benchmark.
- Long-distance moves can cause profile problems and unexpected visibility loss.
- Before the move: update the website, contact page, LocalBusiness schema, social profiles and key citations with the new address.
- Keep the business name identical. Collect documents that prove the business operates at the new address.
- Record the review count, the profile ID and the CID. Run local ranking scans as a baseline.
- Standard process: edit the location in the existing profile, set the pin, save, and complete verification if Google asks.
- Do not create a new profile only because of a move. Do not run two profiles for one business.
- For hard cases, use Google support and keep all messages in one email thread.

## Relevance for 741

- An address change is a high-risk edit with a re-verification step. It needs a written plan, not a quick portal edit.
- The website and schema must show the new address before or at the same time as the GBP edit.
- Baseline data (review count, IDs, ranking grid) must be saved before the change.
