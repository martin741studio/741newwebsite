# AI features and your website (Google Search Central)

- URL: https://developers.google.com/search/docs/appearance/ai-features
- Type: Google official documentation (living page), last updated 2025-12-10
- Fetch date: 2026-10-13

## Key points

- AI Overviews and AI Mode show links to supporting websites.
- They use "query fan-out": many related searches across subtopics. This can show a wider set of links than classic search.
- Google says no special optimization is needed. Standard SEO basics apply.
- A page must be indexed and eligible for a snippet. No other technical requirement exists.
- Best practices: allow crawling, use internal links, keep important content in text, match structured data to visible text.
- Google explicitly says: keep Business Profile and Merchant Center information up to date.
- No special AI files or special schema are needed.
- Controls: nosnippet, data-nosnippet, max-snippet and noindex limit what AI features show.
- AI feature traffic counts in the Search Console Performance report under "Web".

## Relevance for 741

- Removing text content, internal links or crawl access can remove a page from AI answers.
- A nosnippet or noindex tag added by mistake (for example by a plugin) blocks AI visibility. This is a high-risk technical edit.
- GBP accuracy feeds AI answers. Outdated profile or website data can appear in AI summaries.
