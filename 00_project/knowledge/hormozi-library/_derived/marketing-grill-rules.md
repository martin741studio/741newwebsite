# Marketing Grill rules — if/then rules the grill applies

Derived 2026-10-25 for the `marketing-grill` workflow. Format: IF situation THEN action. Src = a file in `../` (the Hormozi library), `visibility-leads-master-reference.md` (same folder), or `00_project/workflow-builds/marketing-grill/playbook-notes-channel-selection.md` (from "The Content Marketing Playbook" notebook). ## Round 1 — what marketing to do

- R-MG1.1 IF 741 (or a B2B agency in general) has limited budget and time THEN prioritize direct outreach (warm/cold) or paid ads over organic content as the primary acquisition engine — outreach/ads give immediate, predictable cash flow; organic content needs 12-18 months to become a real lead engine. Src: `playbook-notes-channel-selection.md` §1.
- R-MG1.2 IF organic content is already running THEN treat it as the nurture/legitimacy layer (passing the "who is this founder" check after an outreach touch or ad click), not the primary lead source, unless Round 1's diagnosis says otherwise. Src: `playbook-notes-channel-selection.md` §1.
- R-MG1.3 IF a prospect is actively searching for the solution right now (intent traffic) THEN that channel (search, PPC, YouTube search) gives higher lead quality but is capped by search volume; IF the prospect is being interrupted while scrolling (interruption traffic, e.g. Meta/TikTok) THEN it scales further but needs a stronger hook. Src: `visibility-leads-master-reference.md` Part 1 §3.
- R-MG1.4 IF the offer itself is not yet proven (no repeatable close) THEN fix the offer before scaling any channel — more traffic into a weak offer wastes the spend. Src: `_derived/visibility-leads-master-reference.md` Part 2 (general Core Four framing) + `revenue-model-100k.md`'s own "fix the funnel before spending on ads" precedent.

## Round 2 — where to reach people

- R-MG2.1 IF 741's own channel-selection question comes up THEN use the creative-agency-owner / high-ticket local-service-owner avatar (`741-youtube-channel-avatar` memory), never the health-client roster — those are real clients, not 741's own lead-gen audience.
- R-MG2.2 IF scaling beyond personal effort is the question THEN consider the four Lead Getter categories in order of effort to activate: customer referrals (highest LTV, lowest CAC) → affiliates/strategic partners → agencies (hired capability) → employees/dedicated staff. Src: `visibility-leads-master-reference.md` Part 3.
- R-MG2.3 IF bringing an outsourced channel in-house is the plan THEN use the three-phase transition: (1) hire a specialized agency to pay down "ignorance debt" and learn the mechanics fast, (2) co-create with a documented 6-month agreement + SOP capture, (3) move to in-house once internal skill matches the agency's, downgrading the agency to a consulting retainer. Src: `playbook-notes-channel-selection.md` §2.
- R-MG2.4 IF a specific name or team assignment from an older memory file would appear in a card THEN verify it against the current `team-roster.md` (or ask Martin directly) before stating it as fact — do not propagate a stale assignment into a card or the playbook. Src: `hand-run.md` (2026-10-25 live correction, "Maya" was stale).

## Round 3 — focus and double down

- R-MG3.1 IF a channel is already chosen and working in principle but underperforming THEN diagnose the specific break (account health/restriction vs. tool problem vs. execution speed) before adding volume or switching channels. Src: `revenue-model-100k.md` 2026-10-21 diagnosis pattern.
- R-MG3.2 IF committing to a channel THEN apply the Rule of 100: 100 primary actions a day (100 outreach touches, 100 minutes of content, or a fixed ad-spend amount) for 100 consecutive days before judging it. Src: `visibility-leads-master-reference.md` Part 6 §1.
- R-MG3.3 IF more than one channel is live or half-built at once THEN apply depth-then-width: fully prove and scale one channel before investing further in a second. Src: `visibility-leads-master-reference.md` Part 6 §3; `playbook-notes-channel-selection.md` §3.
- R-MG3.4 IF deciding what to STOP THEN only pause something that is (a) not yet proven AND (b) competing for the same attention as the current fix — never assume something must stop; ask explicitly and accept "nothing stops" as a valid answer. Src: `hand-run.md` edge case 3.

## Round 4 — how the activity is structured

- R-MG4.1 IF an inbound lead or request arrives THEN speed to contact matters disproportionately: responding within 60 seconds is associated with a ~391% (~5x) lift in conversion versus a delayed response. Src: `visibility-leads-master-reference.md` Part 6 §2.
- R-MG4.2 IF the activity is organic content on a B2B platform THEN 3-5 posts/week is the cited cadence; daily low-effort posting is penalized by modern ranking systems that weight depth and dwell time over frequency. Src: `playbook-notes-channel-selection.md` §3.
- R-MG4.3 IF deciding where the activity gets tracked day to day THEN route it into the existing Morning Grill / Command Center / Outreach & Sales board — never build a second parallel tracker for the same work. Src: `morning-grill-workflow` memory.
- R-MG4.4 IF the activity touches a live channel, spend, or an outreach send THEN the grill still only produces a plan — launching, sending, or spending is its own per-change go, outside this workflow. Src: `inputs-grill.md` Hard Limits (house rules).
