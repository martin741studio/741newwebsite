# 044 The SIMPLE Claude Cowork Setup That Runs my Life (Steal It)
Source: Brock Mesarich | AI for Non Techies, 2026-07-17, https://www.youtube.com/watch?v=V1SWuUosVMI
Reliability: Medium. Practitioner with daily Cowork use, partnered with Anthropic (he says so). Offers a free prompt pack. Non-technical audience. Closest match to the agency Cowork use case.

## Rules (IF situation THEN action. Why.)
- R1. IF you use Claude on the desktop app THEN open Home and toggle from Chat to Cowork mode. The Code button on the left is Claude Code, which targets developers.
- R2. LEVEL 1 foundation: IF you start THEN set up (a) a workspace folder and (b) a CLAUDE.md file. Cowork can only work inside folders you grant. Choose Project or folder, select or create one, and click "always allow" so it does not ask each time.
- R3. IF Claude should know who you are THEN run a "teach Claude who you are" prompt. Claude interviews you with a questionnaire of seven questions and writes a CLAUDE.md with who you are, who you serve, voice and writing rules, how you want to work, and your folder structure. CLAUDE.md loads in every conversation, so you do not re-explain yourself. Edit it by asking Claude or opening it.
- R4. IF a folder is messy THEN point Cowork at it and ask it to organize. In about a minute his folder got sub-folders (receipts, outputs, plugins, skills, guides).
- R5. LEVEL 2 skills: IF you repeat a workflow THEN build a skill. His daily ones: "visualize" (explains a concept as an interactive HTML dashboard) and a PDF guide skill (research a topic, create a PDF explainer infographic in a fixed style).
- R6. IF you get a skill as a zip (a plugin) THEN install it: Customize > Plugins > Add > Upload plugin, then drag in the zip.
- R7. LEVEL 2 connectors: IF you want Cowork to use your apps THEN go to Customize > Connectors > Add > Browse connectors (Gmail, Google Calendar, QuickBooks, Slack, Google Drive). Sign in once.
- R8. IF you want a cross-app overview THEN prompt Cowork to pull from Gmail and Calendar: it returned the most urgent replies, emails waiting for a reply, and tomorrow's calendar.
- R9. IF you want emails in your voice THEN have Cowork read your last 30 sent emails and create an email-voice skill (greetings, sign-offs, length, tone, phrases you use, things you never do, example drafts). Click "add skill" to save. Then it can draft emails that sound like you.
- R10. IF no native connector exists (his examples: Beehiiv, Skool) THEN use the Zapier MCP connector, which reaches 9,000+ apps.
- R11. LEVEL 3 automation: IF you want recurring work THEN create a scheduled task. A task can include your skills. Tasks appear in the left sidebar; "run now" runs one immediately. His four: a morning admin dashboard at about 8 a.m. (Gmail, calendar, AI news as an HTML dashboard), a community-monitoring task at 7 a.m. (questions asked, content gaps, video ideas), and a morning briefing at 7 a.m. (five top stories in your field).
- R12. LEVEL 4 operating system: IF you want one place to look THEN build a live artifact (a mini app inside Claude that pulls from connected apps). Pin it; find all under Artifacts in the sidebar. Prompt example: "Build me a live dashboard I can open up every morning ... Pull from my email and calendar and show today's meetings, anything I need to prep for, and which emails I still need to reply to."
- R13. IF the first artifact is basic THEN keep editing it by prompt (add a to-do tracker, more apps).

## Mistakes to avoid
- Not selecting a folder first (Cowork cannot work outside granted folders).
- Re-explaining yourself every chat instead of keeping CLAUDE.md.
- Sending drafted emails without a sign-off check (he mentions sending through Gmail on your behalf; that is a risk to approve each time).

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- This is the direct template: workspace folder + CLAUDE.md, skills, connectors, scheduled tasks, live artifact dashboard.
- Morning briefing and admin dashboard tasks for the agency day.
