# 017 Learn 95% of Claude Cowork in Under 9 Minutes
Source: Tristen O'Brien, 2026-09-17, https://www.youtube.com/watch?v=R2FFvPDUo7g
Reliability: Medium. Practitioner who uses Cowork daily. Feature list matches Anthropic's descriptions he quotes. No product sold in this video. Some details may have changed since 2026-09-17.

## Rules (IF situation THEN action. Why.)
- R1 IF you want Claude to complete real tasks (not just answer questions) on research, documents, or work across folders, apps and browser THEN use Cowork. Anthropic's split: Claude Code for software engineering, Cowork for non-technical knowledge work. Same engine, no terminal needed.
- R2 IF you want Cowork to reach files on your computer THEN use the desktop app. Cowork also lives on phone and web, but the desktop app is the one that reaches your files.
- R3 IF a weekly task means logging into a site with no app or integration (supplier portal, payroll site, marketplace seller dashboard) THEN give Cowork the task. It opens a browser in the side panel, uses the site you already signed in to, pulls the numbers and drops them in a file. You can watch. This saves about 20 minutes per site.
- R4 IF you want work to continue with your laptop closed THEN run the task in the cloud on a machine in an Anthropic data center. You can also set a schedule: hourly, daily or weekly. You need a paid plan such as Claude Pro.
- R5 IF a job needs local files or the browser on your computer THEN the computer must be awake and the desktop app open. Turn on "keep computer awake" in settings, desktop app, general. The screen still goes off but scheduled tasks run.
- R6 IF you want to continue on another device THEN open the same Cowork session on your phone. It is tied to your Claude account, with the same thread and memory.
- R7 IF the job needs your actual computer (hard drive files, apps, browser) THEN use dispatch from your phone. Dispatch remote-controls your computer, which does the whole job as an agent and returns the result. IF the job lives in the cloud (cloud files, research) THEN the Cowork app on the phone is enough.
- R8 IF you want Claude to reach Gmail, Google Drive, Slack or Calendar THEN add connectors. They are built on MCP. Claude works without them, but connectors make Cowork much more powerful. The speaker uses about a dozen.
- R9 IF you repeat a task THEN turn it into a skill so you do not retype a long prompt.
- R10 IF you do not want to describe the task THEN use "record a skill": click the plus button, then record a skill. Claude records screen, clicks, typing and voice while you do the task once.
- R11 IF you record a skill THEN keep passwords, medical information and other sensitive data off the screen.

## Features and facts mentioned (with version or date if given)
- Six things: give it a job, browser use, keeps working with laptop closed, follows you across devices (with dispatch), connectors, skills.
- Record a skill needs a paid plan (Pro, Max, Team) and the speaker believes it is Mac only for now (he is unsure).
- Browser use is described as relatively new.

## Mistakes to avoid
- Do not assume tasks run with the laptop closed when they need local files. They need the computer awake.
- Do not record sensitive screens.
- Do not use Claude Code if you are not writing code.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Entire video applies. Weekly portal pulls (rank trackers, analytics, ad dashboards) into a spreadsheet fit the browser use case.
- Scheduled hourly/daily/weekly tasks fit recurring client reports.
- Connectors to Drive, Gmail and Calendar cover client deliverables and scheduling.
- Record-a-skill lets non-technical staff capture a process.
