# 027 19 Claude Code Mistakes "Pro" Users Are Still Making
Source: Simon Scrapes, 2026-08-22, https://www.youtube.com/watch?v=icM0ewXGvAw
Reliability: Medium. Practitioner who quotes Anthropic docs; self-corrects older advice. Some figures are his readings of docs and benchmarks. Asks for subscribers.

## Rules (IF situation THEN action. Why.)
- R1. IF your prompt starts with a persona ("senior copywriter with 20 years") or "take a deep breath" THEN delete it. A test of 162 personas over 2,500 prompts showed no gain. Use the words for three things instead: where to look, the definition of done, and a self-check ("Before you finish, verify your answer against ...").
- R2. IF you write "do not do X" THEN write what to do instead (for example "write as smooth flowing paragraphs" instead of "do not use markdown"). Negative rules confuse the model.
- R3. IF you set up a routine THEN remove the connectors it does not need. All connectors are added by default. This is unsafe and costs tokens. You can also remove them from existing routines.
- R4. IF many connectors are on THEN set tool access to "load tools when needed" (chat: plus icon > connectors > tool access). Otherwise all tool definitions load on every message.
- R5. IF you worry about many MCP servers THEN know the old advice is out of date. Tool search is on by default: only tool names load (about 120 tokens), schemas load on demand. Check with `/context`.
- R6. IF you built a skill in the terminal (`.claude/skills/`) and want it in Cowork/Claude Code desktop ("Code Work") THEN add it again via the Customize window (zip upload or recreate). Cowork does not read the folder. It loads skills at session start, so restart after adding one.
- R7. IF you consider subagents or agent teams THEN use them for looking (broad search, parallel investigation) not for doing context-heavy work. Anthropic docs say agent teams use about 7 times more tokens in plan mode.
- R8. IF you add a rule to CLAUDE.md mid-session THEN compact, clear, or restart. CLAUDE.md is read once at session start.
- R9. IF Claude ignores a rule in CLAUDE.md THEN shorten the file. Do not add caps or "IMPORTANT". Models follow roughly 150 to 200 instructions reliably; best files are about 300 to 350 words; keep under 100 to 200 lines. Move detail to other files and reference them. Run `/doctor` ("propose trims to my CLAUDE.md that won't impact performance").
- R10. IF a subagent must follow CLAUDE.md rules THEN restate the rules in the subagent prompt. Subagents get their own system prompt, your task text, and CLAUDE.md, but not conversation history, output style, auto memory, or files already read. Built-in explore and plan agents skip CLAUDE.md. IF a side task needs full context THEN fork the conversation.
- R11. IF you want earlier compaction THEN set the auto-compact window to a fixed token amount (for example 100K). Compaction is no longer a 95% percentage by default. Quality drops long before the window is full.
- R12. IF you hope a 1M window helps THEN know Anthropic's Opus 4.6 test: 93% retrieval at 256K tokens, 76% at 1M. Bigger window is not more memory.
- R13. IF you want partial compaction THEN press Escape twice (rewind). Options: restore code and conversation, restore conversation, restore code, "summarize from here", "summarize up to here".
- R14. IF a plan needs small edits THEN press Ctrl+G in plan mode to edit the plan directly. This saves tokens.
- R15. IF a task is simple THEN do not switch to a cheaper model mid-conversation. Each model has its own prompt cache. Switching rebuilds the cache (example: 100K tokens). Also, turning on fast mode mid-conversation bills the whole context uncached; fast mode uses API credits, not your plan.

## Features and facts mentioned (with version or date if given)
- Verification ladder (Anthropic power-user guide): ask in the prompt; `/goal` (separate evaluator rechecks every turn); stop hooks (block the turn end until a script passes); adversarial review agent.
- Tell an adversarial reviewer to flag only what affects correctness, requirements, or the done condition. Otherwise it keeps finding problems.
- Chat history is kept 30 days by default. Set `cleanupPeriodDays` in `settings.json` (for example 365). Zero wipes everything. Auto memory files are exempt.
- Commands: `/doctor`, `/insights` (HTML report on up to 200 sessions), `/btw` (side question), `/branch`, `/resume`.
- Fast mode: about 2.5 times quicker, Opus. Turn it off with "fast off".
- The Claude Code team cut its own system prompt by about 80% (per speaker).

## Mistakes to avoid
- Personas and filler openings. Negative instructions. Long CLAUDE.md.
- Editing CLAUDE.md mid-session and expecting it to apply.
- Using yourself as the verification loop.
- Letting the 30-day cleanup delete old sessions.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Proposal example: point to the onboarding folder for client notes, define the one-page format, and require "check every number against our notes".
- Cowork needs skills added via Customize, not the `.claude/skills/` folder. Restart after adding.
- Remove unneeded connectors from scheduled routines (client data safety and cost).
- Keep CLAUDE.md short; move client detail to separate files.
