# 024 10 Claude Code Plugins You Need Right Now!
Source: Zero To Mastery, 2026-08-28, https://www.youtube.com/watch?v=IxwZF2nPwvA
Reliability: Medium. Practitioner list video. Benchmark numbers for community plugins come from the plugin authors, and the speaker says they may be exaggerated. Mostly for software developers.

## Rules (IF situation THEN action. Why.)
- R1 IF you add capability to Claude Code THEN know the three terms. An MCP server gives access to one tool or service. A skill is instructions that change how Claude does a task type. A plugin is a container that can bundle MCP servers, slash commands, hooks, and skills.
- R2 IF you want an official plugin THEN open Claude Code and type /plugin, then use the Discover tab. Community plugins install from the plugin's GitHub repo, usually with one command.
- R3 IF Claude must use current library docs THEN install Context7. It pulls live documentation into the prompt, so Claude does not use outdated syntax from training data.
- R4 IF Claude may forget to call a tool THEN use a hook, not only a CLAUDE.md line. The speaker says a CLAUDE.md instruction to check Context7 is sometimes ignored, while a hook fires every time Claude touches code.
- R5 IF you test web flows THEN use Playwright. Prefer the CLI version for Claude Code. It uses fewer tokens than the MCP version, which can blow the context window.
- R6 IF UI designs all look the same (purple gradient, same fonts) THEN install frontend-design. It runs automatically on UI requests and adds a design system.
- R7 IF you code in a language THEN install the matching language server plugin for type inference and static checks. Verified ones: TypeScript, Rust, Python, Go, C#, Java.
- R8 IF you work from Figma designs THEN use the Figma plugin. Paste the URL. The /code connect component command maps Figma components to existing code components.
- R9 IF you want a design framework THEN community plugin impeccable has 23 slash commands and 46 rules. Run /impeccable init first. It asks about project, audience, and brand direction. A design hook runs on UI file edits.
- R10 IF Claude overbuilds THEN try Ponytail. It checks "does this need to exist / is it in the code base / does the standard library do it" before it writes code.
- R11 IF you want a plan challenged THEN run Grill me (from Matt Pocock's skills repo). It interviews you about the plan. You invoke it by slash command, so it runs only when you want.
- R12 IF replies are too long THEN try Caveman. Claimed about 65% fewer output tokens. Code, commands, and errors stay the same.
- R13 IF you want basic discipline THEN Karpathy plugin sets four principles: think before coding, keep it simple, touch only what you need, define success first.

## Features and facts mentioned (with version or date if given)
- Five official plugins named: Context7, Playwright, frontend-design, language servers, Figma. Five community: impeccable, Ponytail, Karpathy, Grill me, Caveman.
- Claimed Ponytail benchmark: about 54% less code, 20% lower cost, 27% faster. Unverified.
- Speaker says GitHub integrated impeccable into Copilot.

## Mistakes to avoid
- Do not install all ten. Pick plugins that fit your work.
- Do not rely on CLAUDE.md alone for must-run steps.
- Do not use the heavy Playwright MCP if the CLI fits.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Grill me: use it to test a client plan or offer before you build.
- Caveman and Karpathy ideas: short replies and "define success first" suit deliverable briefs.
- impeccable init (project, audience, brand) matches a client page design brief. Verify before use.
- Most others target code. Low relevance.
