# 006 Anthropic Just Released 13 New Skills To Level Up Your Claude Setup
Source: Austin Marchese, 2026-10-06, https://www.youtube.com/watch?v=CNsP0mi1DLw
Reliability: Medium. Practitioner commentary on Anthropic's small business plugin. Has a sponsor segment (Clay), a giveaway, and promotes his community and consulting. Some design claims about Anthropic's intent are his own reading.

## Rules (IF situation THEN action. Why.)
- R1 IF you want the plugin THEN open the desktop app, go to settings, select plugins, search "small business" and click install. It is free and gives all 44 skills (31 before, 13 added).
- R2 IF a skill does one job start to finish THEN treat it as a utility skill. IF it only picks which utility skills to call, in which order, and stitches the output THEN treat it as an orchestration skill. Think "crew member" versus "contractor".
- R3 IF an input varies a lot (for example an inbox) THEN build one orchestration skill that routes each item to a specific skill. The inbox manager skill does this.
- R4 IF you repeat a task THEN turn it into a skill with the build agent skill. Then connect outside tools with the build connector skill. Build agent actually builds skills, not agents.
- R5 IF a skill needs a tool with no native connector THEN use build connector as the fallback. Anthropic made it the fallback in 42 of the skills.
- R6 IF you want all outputs on brand THEN use the brand style skill once. Every later asset follows it.
- R7 IF two skills can answer the same request THEN you have a routing collision. Claude does not know which to pick. Example: content strategy ("What should I post?") versus social content engine ("What should we post this month?"). Audit your skill library for overlaps and give each skill a clear boundary. Collisions waste tokens and time.
- R8 IF money or a high cost of error is involved THEN automate the prep, not the decision. Build to the edge of the decision, stop, and bring in a human. Anthropic removed the pricing advice skill with no replacement.
- R9 IF you have several report skills THEN cut to one you actually open. Anthropic deleted Friday brief and quarterly review and kept Monday brief.
- R10 IF a skill is not good yet THEN ship it and improve it. The speaker says Anthropic deleted skills (CRM cleanup, CRM maintenance) without fuss.
- R11 IF you use the speed-to-lead skill THEN first make sure leads come in. It handles inbound leads only. Grow pipeline finds and ranks prospects, writes outreach in your voice, and logs it to CRM.

## Features and facts mentioned (with version or date if given)
- Small business plugin: 44 skills organized by department. Six categories shown: enhancement, sales and leads (4 to 8), marketing (6 to 8), customers and proposals (4 out, 4 in), finance (10 to 12), operations/hiring/briefings (5 to 7).
- New skills named: build connector, build agent, brand style, grow pipeline, speed to lead, SEO and AI visibility, marketing Monday, social content engine, proposal builder, contract review, Monday brief, inbox manager.
- Customer feedback skill moved from support to marketing.
- Anthropic's blog: about 30% of surveyed owners asked for growth help.
- SEO and AI visibility skill takes a public URL and reports how the business shows in AI answers.
- Clay (sponsor) claims 250+ data providers and runs inside Claude Code. This is a sponsor claim.

## Mistakes to avoid
- Do not collect skills without checking overlaps.
- Do not add more reports and check-ins. Cut to one signal.
- Do not automate end to end where errors cost money.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Directly relevant: this is a plugin for the desktop app, not for developers. It has SEO and AI visibility, content strategy, social content engine, proposal builder, contract review and Monday brief skills. Check whether each fits an SEO agency.
- Routing collisions matter once the agency has many skills (SEO, content, social).
- Middle-to-middle automation fits client deliverables: Claude drafts and ranks, the human approves.
