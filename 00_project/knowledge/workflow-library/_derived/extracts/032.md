# 032 The Only Claude Cowork Setup Busy Entrepreneurs Actually Need
Source: Simon Scrapes, 2026-08-16, https://www.youtube.com/watch?v=BMEaJTl3Vo0
Reliability: Medium. Practitioner with a paid academy ("Agentic Academy") and a free brand voice skill in the description. Claims are experience-based, with no hard data. Several points are useful for Cowork.

## Rules (IF situation THEN action. Why.)
- R1 IF you typed the same information into chat more than twice THEN save it as a file and reference it in CLAUDE.md. Work from that folder in the desktop app.
- R2 IF you have several businesses or clients THEN use one folder (context set) for each. Example folder name: "Agentic OS".
- R3 IF you build the base context THEN write three files: brand voice, visual identity, business facts (assets.md, ICP, links, products).
- R4 IF you write brand voice THEN split it per platform (LinkedIn, community posts, email). Keep a core voice file plus a guide per platform.
- R5 IF you have no voice file THEN use the three routes, easiest first: (1) Claude interviews you with 10 to 20 questions, (2) scrape your past writing (sent mail via a Gmail MCP, LinkedIn, replies, client WhatsApps) per platform, (3) update the rules each time you correct a style.
- R6 IF you set a visual identity THEN keep a markdown file plus a tokens JSON (fonts, colors, spacing, header sizes). Build the design system in Claude Design (design systems section) and save the download in the reference folder.
- R7 IF facts are large THEN split them into modular files. CLAUDE.md only points to them, for example: for visuals read the visual identity file, for writing read the brand voice, always load assets.md and the ICP.
- R8 IF you write a skill THEN know that a skill is a folder with an instruction file. It uses progressive disclosure: only the description is loaded first, SKILL.md loads when needed, and extra context sits in separate files. Write a clear description of when to activate and when not to.
- R9 IF you create skills THEN use Anthropic's skill-creator skill for a consistent modular format, or record the process in Claude and generate the skill from the recording (speaker: 60 steps captured in 4 minutes of recording). Recording helps most when there is no API.
- R10 IF you want ready-made skills THEN open desktop app Settings, Plugins, Browse, and install the Anthropic small business plugin (31 skills). Examples: invoice chase, close month, margin analyzer, Canva creator.
- R11 IF you need SEO skills THEN the speaker recommends free open-source "Claude SEO" (32 skills: site audit, technical SEO, E-E-A-T, GEO, local SEO) and "Claude Ads" (12 platforms, 33 skills). He has not tried Claude Ads.
- R12 IF a task repeats THEN make it a scheduled task in the desktop app (new task, then Claude interviews you). It can run in the cloud with the laptop off, you can read logs, and you get a mobile notification.
- R13 IF a scheduled task runs in the cloud THEN it cannot read local folders. Store the context files in Notion or Google Drive and connect them by MCP.

## Features and facts mentioned (with version or date if given)
- Cloud scheduled tasks and skill recording are described as recent releases (video dated 2026-08-16).
- Anthropic does not publish a recommended folder structure for context files. This is the speaker's claim.
- His weekly tasks: invoice reconciliation (17 receipts in one week), competitor analysis watching, YouTube transcripts, spend audits.
- Cowork-adjacent sources named: skills.sh (skill marketplace), Humants (color palettes), Font Pair (font pairings), Anthropic theme factory (judged too basic: no tokens).

## Mistakes to avoid
- Generic output because there is no voice file or no real examples of your writing.
- One single voice for all platforms.
- Searching a huge skill marketplace instead of adapting skills from Anthropic.
- Chatting back and forth for repeat work.
- Scheduling a cloud task that needs local files.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Very high. One context folder per client, with voice, visuals, and facts files, plus a CLAUDE.md index, fits client deliverables.
- Scheduled cloud tasks fit weekly reports and monitoring. Keep context in Drive for them.
- Install and vet the Claude SEO skills before use. They are third-party code.
