# 012 New in Claude Code: Mods and "You Should Know" Plugin
Source: AI Coding Daily, 2026-10-04, https://www.youtube.com/watch?v=_0NSNY7n5lE
Reliability: Medium. Practitioner demo, 5 min, one test run. It describes an Anthropic feature but is not an official channel. The transcript is thin.

## Rules (IF situation THEN action. Why.)
- R1 IF you run several agents or projects and skip the long end-of-task summaries THEN enable the built-in "You Should Know" plugin. It adds a short "worth knowing" / "heads up" block that stresses important points that skimming would miss.
- R2 IF you want the plugin THEN update Claude Code to the latest version and run the plugin enable command. It is built in, so it is not an external install.
- R3 IF a "heads up" item appears in the summary THEN pick one of three actions: "Learn more", "Understood", or "Dismiss". "Learn more" opens a chat about that point.
- R4 IF you worry about cost THEN note the speaker measured no cost overhead. The same prompt cost 85 cents with the plugin and 86 cents without it. Run time was about 2 min vs 1 min 45 s.
- R5 IF you want to extend Claude Code behavior THEN look at "mods". A mod is a small JS or TypeScript file that runs inside the session and can watch what happens.
- R6 IF you read an agent summary THEN read it for consequences, not only for facts. The speaker's example: "server time zone, not user time zone" matters because the two can differ.

## Features and facts mentioned (with version or date if given)
- "You Should Know" is a Claude Code plugin released with the new "mods" feature (video dated 2026-10-04). The plugin is one implementation of mods.
- Mods are described in an Anthropic article with an 11-minute reading time. The article is linked in the video description. The transcript does not give the URL.
- To remove the plugin, use the plugin disable command. Then it no longer shows in the plugin list.

## Mistakes to avoid
- Do not assume the agent summary is read. The speaker admits many people do not read it.
- Do not assume the plugin changes the summary structure much. The speaker saw a similar structure without it. He guesses newer Opus and Sonnet models already improved the summaries.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Weak link only. The idea "make the agent flag what you must know and what can go wrong" fits client deliverable QA. Test on a real client task before you rely on it.
- The video gives no mod example for non-developers.
