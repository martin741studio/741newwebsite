# 029 How to Use Claude Cowork (Step-by-Step Tutorial)
Source: Kevin Stratvert, 2026-08-17, https://www.youtube.com/watch?v=YYr7hw5EAtk
Reliability: Medium. Practitioner tutorial (clear, non-technical). Sponsor read for Zapier MCP in the last part. Uses a Windows desktop app demo.

## Rules (IF situation THEN action. Why.)
- R1. IF you want Claude to do work, not only answer THEN switch from Chat to Cowork (toggle at the bottom of the prompt box). Cowork works through files and tools on your computer and in the cloud.
- R2. IF you want Cowork with local files and folders THEN use the Claude Desktop app (Get Apps and Extensions in the profile menu). The web version allows uploads and screenshots only. Cowork needs a paid plan.
- R3. IF Cowork must read your files THEN click the folder button, select the folder, and click Allow. Cowork then works with the files in that folder.
- R4. IF data sits in mixed formats (text, PDF, spreadsheet) THEN point Cowork at the folder and ask it to analyze all of it and build an interactive dashboard. It combined the files, flagged a data quality issue, and wrote key insights.
- R5. IF you want to keep a result THEN save it as an artifact (interactive page). Find it later in the sidebar under Artifacts. You can also download it.
- R6. IF files live in the cloud THEN add a connector: Customize > Connectors > Connect (Google Drive example). Then prompt in plain words, even vague ones ("find the remaining sales data in Google Drive and update our dashboard").
- R7. IF the result is not right THEN keep prompting in the same chat (example: change the dashboard to the brand colors blue and maize).
- R8. IF you repeat the same analysis each week THEN ask Claude to create a skill. Prompt used: a skill that checks for new sales data, compares with the previous week, pulls out the key insights, and updates the dashboard. Review the skill on the right, refine it by prompt, then save it.
- R9. IF you want it to run by itself THEN schedule it with a prompt ("run this skill every Monday morning"). The skill defines how; the schedule defines when.
- R10. IF you need many more apps THEN use Zapier MCP: one connection to thousands of apps. In Zapier, open MCP Servers, choose Claude, copy the prompt and paste it into Claude. Choose which apps and which actions Claude may use.
- R11. IF you give Cowork write access to apps THEN select only the actions you want. The speaker says this keeps you in control.

## Features and facts mentioned (with version or date if given)
- Cowork requires a paid Claude plan (not free).
- Claude Desktop is available for Windows, Mac, and Linux.
- Trello is a built-in connector; the demo used Zapier MCP to create a Trello card with an action plan from the sales analysis.
- The progress of a Cowork task shows in a panel on the right.

## Mistakes to avoid
- Expecting local-folder access in the web version.
- Re-typing the same instructions every week instead of saving a skill.
- Giving a tool all actions when it needs few (via Zapier MCP).

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- This video is the closest match: folder of mixed client files > dashboard artifact > skill > weekly schedule.
- Weekly client report pattern: skill compares this week to last week, updates a dashboard, runs Monday morning.
- Google Drive connector for client data; Trello or similar task creation via Zapier MCP.
- Brand-color changes by plain prompt.
