# 008 Claude Code Just Dropped MODS. (Master it in 10 Minutes).
Source: Tristen O'Brien, 2026-10-05, https://www.youtube.com/watch?v=LDn7rQKIFro
Reliability: Medium. Practitioner demo. The video is sponsored by Higgsfield and the Claude Photos mod runs on its paid credits.

## Rules (IF situation THEN action. Why.)
- R1 IF you want a feature Claude Code lacks THEN describe it to Claude Code and it builds the mod into itself. A skill tells Claude how to do a job and a connector plugs into an app. A mod runs inside Claude Code and can change the screen.
- R2 IF you build a mod THEN update Claude Code first. The speaker says version 2.1.287 or newer (he is not sure of the number).
- R3 IF Claude asks you to reload after building a mod THEN say yes. The mod appears as soon as Claude finishes.
- R4 IF you dislike something in the mod THEN tell Claude in plain language what to change.
- R5 IF you want a mod to last THEN ask Claude to save it as a plugin and install it. Mods Claude builds are temporary by default.
- R6 IF someone shares a mod THEN install it like any plugin: type /plugin, search, install.
- R7 IF you want less noise on screen THEN use a clean view mod. It hides tool rows and shows a checklist and a short summary.
- R8 IF you change model or effort often THEN use a control panel mod instead of /model and /effort.
- R9 IF you want to see and size the helper agents THEN use an agent dock mod. It lets you pick the team size (up to 50 in his build) and the helper type (fast and cheap or the same model). Each agent gets a card with a progress bar. Large teams use your plan much faster, so his mod warns before going big.
- R10 IF a mod uses paid credits (images, video) THEN make it show the credit cost and pause until you click yes.
- R11 IF a mod runs in the background THEN remember it uses subscription credits.

## Features and facts mentioned (with version or date if given)
- Mods came out October 1 (2026). On by default after you update.
- Mods work in the Claude Code terminal and in the Claude tab of the desktop app. They do not work in Claude chat.
- A mod listens to events (Claude runs a file or command). It can watch the event, change it, or handle it itself.
- Mods cost nothing extra. You need a paid plan that includes Claude Code.
- A mod is a type of plugin. Claude Code has a built-in skill that teaches Claude to build mods.
- His six mods: Clean View, control panel, Agent Dock (/doc), session bar, Claude Photos (/create, Higgsfield connector, Nano Banana Pro, 4K), Roadtrip (racing game with Claude quiz questions while you wait).

## Mistakes to avoid
- Do not forget to install the mod, or it is lost.
- Do not select a 50-agent team without checking plan usage.
- Do not let a credit-based mod spend without approval.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Mods run in the Claude tab of the desktop app, so non-developers can use them.
- Clean view suits someone who wants only progress and a summary, not tool noise.
- A credit-approval gate is a good pattern for paid tools.
- Most examples are for fun or personal comfort. Business value is limited.
