# 021 Claude Code: The Advanced Guide (99% of Devs Skip These Features)
Source: Tech With Tim, 2026-09-07, https://www.youtube.com/watch?v=kt5a-TXmWew
Reliability: Medium. Practitioner with live demos. Contains sponsor reads (Granola, Wispr Flow) and a free community link.

## Rules (IF situation THEN action. Why.)
- R1. IF a task needs its own rules (read-only tools, cheaper model, review only) THEN create a custom subagent as a markdown file in `.claude/agents/`. Each file has `name`, `description`, allowed tools, and an optional model.
- R2. IF you run many subagents and want lower cost THEN set a cheaper `model` in the agent file. The speaker says this reduces cost.
- R3. IF you want to check that subagents loaded THEN run `/context`. It lists the custom subagents.
- R4. IF you want a lean main thread THEN delegate work to subagents. Claude brings back only the subagent's reply, so each subagent has its own context window. Agents get "dumber" near the context limit.
- R5. IF you want a repeatable workflow THEN write a skill in `.claude/skills/` with a `name`, a `description`, and the steps. The model sees only name and description before it decides to load the skill.
- R6. IF a skill must never run without you (deploy, rollback) THEN set `disable-model-invocation: true` in the skill. The skill stays out of context and runs only when you type `/skillname`.
- R7. IF you want to pass a target to a skill THEN type the argument after the command, for example `/deploy staging`.
- R8. IF you want to see all skills THEN type `/skills`. Locked skills show as locked.
- R9. IF you want automatic actions at certain events THEN configure hooks in `settings.json` (events: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, and others). A hook runs a command or script.
- R10. IF a PreToolUse hook script exits with code 2 THEN the tool call is blocked. Use this for a "block dangerous commands" script.
- R11. IF you want auto-formatting THEN use a PostToolUse hook with matcher `Edit|Write` that runs a formatter such as prettier.
- R12. IF several agents work on the same project THEN start each with `claude --worktree <name>`. Each agent gets an isolated copy of the repo. Later ask Claude to merge the worktrees.
- R13. IF you want Claude inside a script THEN use headless mode: `claude -p "prompt"`. Pipe input in (for example `cat build.log | claude -p "why did this fail?"`).
- R14. IF a script needs reliable output THEN add JSON output format and parse with `jq`. JSON also returns cost, number of turns, and duration in ms.
- R15. IF you want to limit a headless run THEN add `--allowedTools Read`.

## Features and facts mentioned (with version or date if given)
- `/rewind` restores code and conversation to an earlier checkpoint (restore code, conversation, or both).
- `claude --continue` resumes the last conversation in the folder. Sessions are stored locally and have IDs.
- `claude -n <name>` names a session. `claude --resume <name>` returns to it.
- `/branch` forks the current conversation without overwriting the main session. Use `/resume` to switch back.
- The Granola MCP server (official, released earlier in 2026) lets Claude query meeting transcripts.
- Auto mode exists as a permission mode in the demos.
- Hook config sits in `settings.json`; hook scripts sit in a hooks folder under `.claude`.

## Mistakes to avoid
- Do not let agents edit the same files in one folder without worktrees.
- Do not let the model auto-run destructive skills. Lock them with `disable-model-invocation`.
- Do not run everything in one huge thread. Quality drops near the context limit.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Skills as reusable client-deliverable workflows (audit, report, outreach). Lock risky ones (send email, publish) with `disable-model-invocation`.
- Subagents with read-only tools for review tasks (QC of a page spec before delivery).
- `claude -p` can run recurring jobs from a script or cron (for example a weekly report), but the demo is code-focused.
- `/rewind` and `/branch` help when a page rewrite goes wrong.
- Granola/meeting-note MCP idea: pull call transcripts into Claude.
