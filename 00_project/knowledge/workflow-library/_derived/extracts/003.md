# 003 Claude Mods Are Insane... You Need To Try These Right Now
Source: AI LABS, 2026-10-09, https://www.youtube.com/watch?v=ERNqRK6sMJY
Reliability: Medium. Practitioner software company. Sells its refined mods in a paid community (AIABS Pro). Has a sponsor segment (Runway) that is not relevant.

## Rules (IF situation THEN action. Why.)
- R1 IF you want a feature Claude Code lacks THEN build a mod. A mod can change Claude Code's interface and behavior, and it is always running. Skills and plugins only add capability and cannot change the screen.
- R2 IF you want to create a mod THEN give Claude Code a prompt that says what it should do. Claude loads the built-in skill called plugin-authoring and writes the code.
- R3 IF Claude asks about hot reload while making a mod THEN allow it. The mod loads when Claude finishes its turn, and you do not reload by hand.
- R4 IF you want the mod in other sessions THEN ask Claude to install it. A freshly made mod works only in the current session. It is saved in a temporary spot that is cleared later.
- R5 IF your prompts are rough THEN use a prompt-enhancer mod. It rewrites your prompt in the prompt bar, names fitting installed skills, lists big decisions to ask you first, and describes the finished result. It does not send the prompt. You check and send it.
- R6 IF Claude asks you to choose a design style THEN use a mod that opens a site showing each style visually. Words alone gave designs that sounded good but looked bad.
- R7 IF you worry about silent guesses THEN use an assumptions mod. A strip above the prompt shows the count. With an empty prompt bar, press 0 to open the list. Mark each assumption right or wrong with tab. Wrong ones go back to Claude as a new prompt.
- R8 IF ideas pop up while Claude works THEN save them on an idea shelf mod (per project, kept after closing Claude Code). Send them later as prompts.
- R9 IF you run many sessions THEN use a sessions mod that shows which wait on you, which work and which are done. Open it with the sessions command or Ctrl X then tab.
- R10 IF several sessions work in the same folder THEN use a session-tracker mod so two sessions do not do the same task.
- R11 IF Claude answers are too technical THEN use a mod that makes Claude rewrite the final answer simply, with next steps. It can also block summaries between tool calls. The creators added a check with a Haiku model to enforce the rules.

## Features and facts mentioned (with version or date if given)
- Mods can draw a panel beside the chat or a strip above the prompt box, with buttons and text boxes. They can redraw parts of the screen (action rows, question box).
- Two built-in mods: the diff command (changes since last git commit) and "you should know" (a side agent that watches long sessions and shows notes above the prompt). The second is off by default.
- Marketplace: claudemod.com.
- Custom pets are possible, for example a pixel pet that reacts to pass or fail.
- Keys set by the creators' mod: Ctrl X then tab selects the enhance button. In full screen mode you can click buttons.

## Mistakes to avoid
- Do not forget to install the mod if you want it beyond the current session.
- Do not accept design styles described only in words.
- Do not let Claude's assumptions pass unchecked. Wrong ones show up later when something breaks.

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Prompt enhancer, assumptions list and session tracker help anyone who runs several client tasks in parallel.
- The video covers Claude Code only. It does not mention Cowork.
