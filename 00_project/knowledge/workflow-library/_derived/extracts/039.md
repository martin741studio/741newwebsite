# 039 The ONLY Claude Skills Tutorial Beginners Need in 2026
Source: 100x Engineers, 2026-08-01, https://www.youtube.com/watch?v=TyB7kLZPVKo
Reliability: Medium. Practitioner tutorial in Claude's chat app (non-developer friendly). Sells a 6-month cohort program. UI paths are from the Aug 2026 app.

## Rules (IF situation THEN action. Why.)
- R1. IF you want to use skills in Claude THEN go to Customize > Capabilities and turn on "code execution and file creation". It is on by default in most accounts.
- R2. IF you want automatic skill use THEN just prompt normally. Claude picks a relevant skill (example: it loaded the pptx skill for "turn this into a deck").
- R3. IF you want to force a skill THEN type `/` in the chat, pick the skill, then type your prompt.
- R4. LEVEL 1: IF you start THEN browse built-in skills at Customize > Skills > Browse and click plus to add. Example: the `/learn` skill changed Claude's reply from a generic answer to questions about your starting point.
- R5. LEVEL 2: IF you want your own brand style THEN modify a default skill instead of writing from scratch. Prompt used: use `/brand-guidelines` and create a new skill by duplicating it, following my uploaded brand colors and typography, call it "brand book", and give me an option to save it. Result: decks came out in the user's colors.
- R6. LEVEL 3: IF you need domain skills THEN open Customize > Browse > Plugins. Plugins bundle skills by domain (marketing, productivity, sales, data, finance). Marketing has eight skills (brand review, campaign plan, competitive brief, content creation, and others). Install the whole package or pick skills.
- R7. IF a plugin lists connectors THEN connect the tools (Slack, Canva, Figma, HubSpot, Amplitude, Notion, Ahrefs, Klaviyo, Supermetrics for marketing). Analogy: Claude is the brain; connectors are hands and legs that act.
- R8. IF a tool has a partner skill (Plugins > Partners) THEN install it AND connect the account under Connectors. Example: Canva partner skill has six skills (brand check, implement feedback, design feedback, edit design, resize for social media, bulk create). Resize for social media made 1:1, 9:16, 3:2, 4:3 versions from one image inside Claude.
- R9. LEVEL 4: IF you create a custom skill THEN type `/skill-creator`. Give very detailed instructions (structure, length, tone), upload reference documents (his had 100+ scripts), and invite questions ("feel free to ask me more questions").
- R10. IF the skill creator offers test cases THEN say yes. Review the sample outputs, give feedback (his hooks were too generic; the skill should ask for the real name instead of writing around it), repeat, then say "package the skill" and save it.
- R11. IF a skill works THEN a one-line invocation is enough (`/reel-script-writer` plus an article link, with no extra prompt).
- R12. PRO SECRET: IF you want to write better skills THEN read Anthropic's own skill files in Claude's sandbox. Ask Claude to run a bash command that lists the skills directory, then open a folder (for example the pptx folder). He saw three patterns: (1) a very detailed description that lists every trigger word, (2) most of the file warns what not to do, (3) real Python scripts sit inside the skill. Copy that pattern.
- R13. IF you learn skills THEN start with level 1 today and level 2 tomorrow. "Skills are learned by reps."

## Features and facts mentioned (with version or date if given)
- A skill is a markdown file of instructions and guidelines for a task.
- Plugins view lists connectors per domain (marketing: Slack, Canva, Figma, HubSpot, Amplitude, Notion, Ahrefs, Klaviyo, Supermetrics; sales: Slack, HubSpot, Close, Monday, Notion, Fireflies).
- Sample skills visible in the speaker's list: campaign planning, competitive brief, content draft, brand review.

## Mistakes to avoid
- Writing a custom skill from scratch when a default skill is close.
- Writing a skill without reference documents.
- Skipping test cases and feedback rounds.
- Installing a partner skill without connecting the account.
- A vague skill description (it will not trigger).

## Relevant for a non-developer business workflow (SEO/marketing agency, Cowork, scheduling, client deliverables)
- Directly useful: marketing and sales plugins (brand review, campaign plan, competitive brief, content creation, SEO tools like Ahrefs via connector).
- Brand-book skill pattern for per-client brand colors and fonts in decks and documents.
- Custom skill from reference documents (past scripts, past reports) to match a voice.
- Canva partner skill to resize assets for social media.
