## Key points
- A cloud agent runs a long task on its own remote machine. The user can close the laptop and check the result later.
- The agent plans, edits, runs commands, and tests its work over minutes or hours.
- The agent can open a pull request when it finishes.
- The agent attaches videos, screenshots, and logs to the pull request. A reviewer can check the work without a local copy.
- The page says the agent comes back with proof that the work is done. The evidence travels with the result.
- A human can take over the remote desktop of the agent and make edits.
- People can start agents from the editor, the web, mobile, Slack, GitHub, or Linear. Automations can start them on a schedule or on events.
- Each run is sandboxed. Cursor applies secret redaction and network rules per run.

## Gaps / bias notes
