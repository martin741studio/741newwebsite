# Notion: Custom Agents (triggers, Activity tab, version history)

- Fetched: 2026-10-13

## Key points
- Custom Agents run on schedules, on Notion events (new page, property change, comment), or on Slack events.
- Filters limit runs to relevant items, for example one status or one keyword.
- The Activity tab logs every run. Each entry shows the trigger, the actions, and any errors.
- A user can open one run and see each step and the reason for an error.
- Version history shows who changed the agent setup, when, and what changed. A user can restore an old version.
- Agents use only the pages and databases that a person grants. A link in the instructions does not grant access.
- Three permission levels exist. Only Full Access users see the activity logs. Can Edit users can review activity.
- Sub-agent hand-offs and premium models use credits. An Insights tab compares model use, quality, and credits across runs.
- Enterprise admins see agent setup changes in the audit log.

## Gaps / bias notes
- The page describes no approval step before an agent acts.
- The page does not say how Notion marks page edits that an agent made.
- Run logs are per agent, not per client or per project.
