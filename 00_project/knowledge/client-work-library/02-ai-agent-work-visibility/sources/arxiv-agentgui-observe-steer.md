# AgentGUI: an interface for observing and steering long-running AI agents

- URL: https://arxiv.org/abs/2607.26300
- Type: study (arXiv preprint, Zhao, Sohn, Zheng, Moor)
- Published: 2026-07-28 (v1), revised 2026-08-04 (v2)
- Fetched: 2026-10-13

## Key points
- AgentGUI is a local interface to watch and steer several long agent sessions at the same time.
- It shows rich visual views of each agent trajectory (the steps it took).
- It supports manual steering by a human and automatic steering against drift.
- It works across open-source and frontier agent frameworks.
- In a controlled user study, people found key items in agent traces about 38% faster (p = 0.023).
- Automatic drift prevention raised task completion of small local models by up to 34 percentage points.

## Gaps / bias notes
- Preprint, not peer reviewed. Small study.
- The study covers developers and traces, not business task lists.
- I read only the abstract page.
