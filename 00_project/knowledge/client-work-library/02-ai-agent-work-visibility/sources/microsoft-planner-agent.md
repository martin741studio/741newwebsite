# Microsoft Planner: execute tasks with Planner agent

- Type: official doc

- Fetched: 2026-10-13

## Key points
- A user assigns a task to the Planner agent from any view. In Board view, the user can drag the card into an "Assign to Planner agent" bucket.
- The agent has four task states: Queued, In progress, Needs input, and Done.
- "Done" means the agent finished and the output is ready for human review. It does not mean the task is complete.
- The page says the agent "will never mark a task as complete". A human reviews and closes the task.
- Board view can group by agent state: All pending, Assigned to agent, Couldn't complete, and Ready for Review.
- All agent output goes into one component inside the task details. The evidence lives on the task.
- When the agent needs input, it writes questions in that component. The human answers there and selects Regenerate. The task goes back to the agent queue.
- After review, a human can comment on or edit the output and ask for a new version.

## Gaps / bias notes
- The page shows no cost or time per run.
- The page does not describe sources or provenance for the output.
- The feature is still rolling out. Names and buckets can change.
