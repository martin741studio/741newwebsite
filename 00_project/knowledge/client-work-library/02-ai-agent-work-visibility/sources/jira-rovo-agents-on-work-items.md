# Jira Cloud: collaborate on work items with AI agents

- URL: https://support.atlassian.com/jira-software-cloud/docs/collaborate-on-work-items-with-ai-agents/
- Type: official doc
- Published: living page, fetched 2026-10-13
- Fetched: 2026-10-13
## Key points
- A user can start an agent from the Agents button or the assignee field. An @mention in a comment also works.
- A workflow transition or a board column can also start an agent.
- A workflow transition or a board column starts the agent when any team member moves the item into that status. This makes agent work part of the normal flow.
- The agent uses the summary, description, comments, and attachments of the item. It can also use other items on the site as context.
- The output goes into a separate "Agents" section on the work item. The "Agent sessions" area shows the activity.
- At first, only the person who started the agent can see the output. That person edits it and then shares it as a comment or attachment.
- "Publish" completes the agent task but does not share the output. Sharing is a separate human step.
- Admins control which agents are available, and for which surfaces.
- Admins see credit usage per user and per feature. Admins get alerts at 80% and 100% of the usage limit.

## Gaps / bias notes
- The page gives no formal status list for agent work.
- The page does not describe an audit log for agent actions.
- Credit rules start on a future date (December 3, 2026) and can change.
