# Vibe-GUIDE: a graph-based user interface in IDEs for oversight in vibe coding

- URL: https://arxiv.org/abs/2609.23859
- Type: study (arXiv preprint, Chou, Lee, Choudhuri, Ma)
- Published: 2026-09-20
- Fetched: 2026-10-13

## Key points
- When people only give intent and approve agent work, they slowly lose their understanding of the project. The authors call this "cognitive debt".
- Lost understanding makes later oversight weaker. The human approves work that they no longer fully know.
- Vibe-GUIDE shows a live map (graph) of the project by module. It sits next to the chat with the agent.
- The map is a shared view that both the human and the agent use over time.
- In a randomized study with 16 developers, the map group kept better project understanding and steady task performance.
- The map also kept developers mentally engaged in oversight, compared with chat only.

## Gaps / bias notes
- Small sample (16). Preprint.
- Software projects only. The transfer to client work views is an inference.
- I read only the abstract page.
