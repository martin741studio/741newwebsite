# Schema.org: Action (and ActionStatusType)
- URL: https://schema.org/Action
- Type: Vocabulary specification (footer V30.1, 2026-09-16)
- Published: living page, fetched 2026-10-13
- Fetched: 2026-10-13

## Key points
- Action describes something that an agent did or will do.
- agent is the direct doer. participant names others who took part indirectly.
- object is the thing the action works on. result is the thing the action produces. instrument is the tool used.
- startTime and endTime frame the action. error holds the cause of a failure.
- actionStatus uses four values: PotentialActionStatus, ActiveActionStatus, CompletedActionStatus and FailedActionStatus.
- The four values give a small, neutral status core that fits tasks and agent runs.
- Gaps / bias notes: The vocabulary targets web markup, not databases. agent allows only Person or Organization, so a software agent needs a local extension.
