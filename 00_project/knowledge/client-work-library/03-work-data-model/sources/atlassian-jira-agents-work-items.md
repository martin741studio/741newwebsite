## Key points
- Jira offers four ways to bring in an agent: the agent picker on the work item, an @mention, a workflow transition rule, and a board column (team-managed spaces only).
- A space admin can add a "Trigger agent action" rule to a transition. The agent then runs each time a work item enters that status.
- Only the person who added or triggered the agent can talk to it. Everyone with access sees that an agent ran.
- Agent output is private to that person at first. The person reviews it in "Agent sessions", edits it, and then shares it as a comment.
- Publish finishes the agent task but does not share the output. Sharing is a separate human step.
- A site admin enables the AI features. Each agent needs the work item surface switched on.
- Each agent run uses Rovo credits. Credit allowances start on 3 December 2026.
- Gaps / bias notes: The page does not list which fields an agent can change. It states no release stage. It is a vendor view.
