## Key points
- Agents act like workspace users. Users can mention them, delegate issues to them, and see their comments.
- When a user assigns an issue to an agent, Linear treats this as delegation. The agent appears in a separate Delegate field.
- The Delegate field works as a filter in custom views and in Insights. Teams can measure how much work agents do.
- Delegated issues stay in the "My issues" view of the human. The human keeps oversight of the work.
- Workspace admins install agents and choose which teams each agent can access. The install permissions set what the agent can do.
- Agents cannot sign in, use admin functions or manage users.
- Guidance at workspace and team level tells agents the house rules.
- Gaps / bias notes: The page does not describe how status changes when an agent works. It gives no dates. Linear's own blog (not fetched) states that the human assignee stays responsible.
