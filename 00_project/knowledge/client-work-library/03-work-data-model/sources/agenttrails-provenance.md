# AgentTrails: Towards Trust and Reuse for Agentic Tasks

- Published: 2026-07-21 (v1)
- Fetched: 2026-10-13

## Key points
- A flat, time-ordered agent log hides which step used or made which artifact.
- The paper turns agent runs into provenance graphs. Tool calls are activities. Inputs and outputs are artifacts.
- Edges link each activity to the artifacts it used and the artifacts it produced.
- The graph shows hidden dependencies that the log does not show.
- Several runs can merge into one aligned graph. Teams can then compare runs and find repeat patterns.
- Repeat patterns can become reusable skills.
