# New dashboard experience now the default
- URL: https://github.blog/changelog/2026-10-01-new-dashboard-experience-now-the-default
- Type: Product changelog (GitHub)
- Published: 2026-10-01
- Fetched: 2026-10-13
## Key points
- The new GitHub dashboard is now the default for all users.
- One view shows active agent sessions next to issues and pull requests. Agent work and human work sit side by side.
- Filters set what each section shows.
- Each list shows a maximum of 12 items. The cap keeps the start view short.
- The update stream moved to a separate Feed tab. The work view and the feed are two different surfaces.
- The user can start work from the dashboard: assign an issue to the coding agent or open a pull request.
- Users can switch back to the old view during the change period.
## Gaps / bias notes
- Short changelog. It gives no research reason for the 12-item cap or the feed split.
