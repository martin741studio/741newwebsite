# New project activity feed

## Key points
- The project overview page now has an activity feed with the latest updates.
- The feed shows production versions (with the last published version), preview versions, and agent runs.
- Filters: All, Production, Previews, Agent runs. The user can separate agent work from human work in one click.
- Agent runs show what agents work on and what the team prompted.
- Each item has a status, for example "in progress" or "published", and a preview link.
- The feed replaces separate searches for deploy links, preview links and agent run lists.
- The feed is part of a plan to simplify the dashboard.
