# AI agent UX design
- URL: https://www.parallelhq.com/blog/ai-agent-ux-design
- Type: Design agency article
- Published: 2026-07-28 (Robin Dhanwani)
- Fetched: 2026-10-13
## Key points
- Use a "human on the loop" model. The system runs on its own, and the person monitors and can step in.
- Keep one central activity log. Fully autonomous tasks need a log that the person can read after the fact.
- High-risk actions need explicit approve and reject controls. In draft mode, nothing goes live before approval.
- When a person rejects an output, ask for the reason.
- Make undo easy and visible. Archive instead of delete for destructive actions.
- Show evidence: mark the exact source lines behind an output. The article reports a health-tech case where adoption rose after this change.
- Show a confidence signal and flag low-confidence items for manual review.
- Do not use chat as the default surface for dense workflow work. Put the agent output into structured views.
- Send daily or weekly digests of automated actions. The agent reports when a job ends or gets stuck.
## Gaps / bias notes
- Agency marketing content. The health-tech adoption figure is anecdotal and has no public source.
- The 85% confidence threshold is an example, not a tested value.
