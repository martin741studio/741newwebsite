## Key points
- The Client Portal is one area per client. It holds branding, dashboard visibility and user access together.
- The agency selects which dashboards each client user can see. The example hides test dashboards that are not ready.
- Visibility changes apply at the next client login.
- Branding: one client logo and one brand color per client. Without them, the account defaults apply.
- Access has three layers: Client Access (which clients a user sees), User Permissions (which actions and features), Dashboard Visibility (which dashboards inside a client).
- Integration dashboards and sections can be set per user.
- The agency can log in as the client user to check the client view.
