# Nobody wants another chatbot: 7 interface architectures worth building

## Key points
- Keep the current output on a separate canvas. Users must not re-read a long chat to find the latest state.
- Agents can assemble dashboards from a fixed set of components (charts, tables, forms).
- Show agent activity in a panel next to the conversation: tool calls, steps, reasons.
- Pause before consequential actions (writes, spend, external messages). Show a confidence signal and allow a step override.
- Proactive agents must give a compact summary of what they did. Each summary needs a plain explanation and an easy undo.
- Shared trust controls: status indicators, diff or preview views, per-action audit logs, one-click overrides.
## Gaps / bias notes
- Architecture overview for builders. No user testing.
- Focus on the operator, not on an end client.
