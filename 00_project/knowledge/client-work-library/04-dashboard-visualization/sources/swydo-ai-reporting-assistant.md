# AI reporting assistant (Swydo AI)
- URL: https://help.swydo.com/en/articles/13407710-ai-reporting-assistant
- Type: Product help page (Swydo, marketing client reporting tool)
- Published: 2026-08-27 (page date)
- Fetched: 2026-10-13
## Key points
- The assistant sits inside each client report. It helps write summaries and insights.
- Fixed prompt types: Summary, Wins, Issues, Recommendations. A related changelog (December 2025) and Swydo product pages name the same four.
- The user can point the assistant at one section or one widget of the report.
- The user puts the output into the report, for example in a text widget. The human edits and decides.
- The user can change widgets and report layout by chat, and save prompts for reuse.
- Swydo says it does not use client data to train models.
