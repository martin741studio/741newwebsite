## Key points
- Three dashboard types: operational (what happens now), analytical (explore and compare), strategic (progress over weeks and quarters).
- Start from the decision the user must make. Every metric must link to an action.
- Put the most decision-critical item where it shows at load. Give it the most visual weight.
- Common order: 3–5 key numbers at the top, trends in the middle, detail tables at the bottom.
- Attention drops across repeated cards. Later cards get missed.
- Alerts and exceptions go to the foreground. Operational users must see problems in seconds.
- Keep summaries on the main view and open detail on request (progressive disclosure).
- Use color for status, not for decoration. Use it sparingly so alerts stand out.
- Fewer filters and options give faster decisions. Charts must be readable without hover.
