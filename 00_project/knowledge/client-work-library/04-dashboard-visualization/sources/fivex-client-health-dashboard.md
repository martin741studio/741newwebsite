# Marketplace agency client health dashboard: profit and risk

- Type: Agency practitioner article
- Published: 2026-08-24 (Lisa van Broekhoven)
- Fetched: 2026-10-13
## Key points
- Agencies need an internal client health dashboard. A client reporting dashboard is a different tool.
- Four health areas: commercial (margin, fees), operational (delivery issues), decision (approval speed), service (retainer hours, escalations, out-of-scope work).
- Scoring: each client starts at 0 each week and gets points per signal. Example: +2 when a client decision waits more than 5 business days.
- Bands: green 0–5, amber 6–11, red 12 or more.
- Lane actions: green gets the standard automated cadence. Amber needs one agreed corrective action before the next call. Red needs senior action on scope, budget or ownership.
- Each red or amber signal needs one named owner and one concrete next action. A vague flag is not enough.
- Review the score weekly in the internal client review, not only in the monthly client report.
- Start with 8–10 signals. Score the full portfolio by hand once. If all clients are red or all are green, change the thresholds.
- A client can grow in sales and become less healthy to serve. Use profit and effort signals, not only results.
## Gaps / bias notes
- Written for e-commerce marketplace agencies. The point values need new signals for local SEO.
- Example case only, no data set.
