# Weekly client status report template
- URL: https://superthread.com/learn/weekly-client-status-reporting
- Type: Vendor guide and template (project-management tool)
- Published: 2026-07-23 (Superthread Team)
- Fetched: 2026-10-13
## Key points
- Six sections: Summary, Completed, Next, Decisions needed, Risks and changes, Time/budget/scope.
- Report finished outcomes (approved concept, delivered asset). Do not report activity (meetings, emails).
- Put all client actions in one table: decision, owner, deadline, effect of a late answer.
- State risks early: what changed, how serious, what the response is.
- Use the same format each week. Keep old updates for reference.
- Build the update from the board, the decision log, notes and time entries. Do not build it from scattered messages.
- An AI agent can draft the update. A person reviews and approves it before the client sees it.
- Publish in a shared client space and send a link. Do not copy versions into email or chat.
- The client must read it in minutes.
