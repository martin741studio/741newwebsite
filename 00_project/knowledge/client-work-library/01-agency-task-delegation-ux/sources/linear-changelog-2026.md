## Key points
- 2026-07-20, Loops: a user writes a recurring job in plain language. It runs on a schedule or on an event.
- Loops can check new issues, research causes, and hand them to coding agents. They can turn meeting notes into follow-up work.
- Anyone with access can read a Loop's instructions and inspect each run. The run log is the evidence.
- 2026-07-23: agents edit project text and documents. The tool highlights each agent change for human review.
- 2026-07-30: delegated issues show under My Issues, Assigned, with the agent session status.
- 2026-08-13: teams can lead initiatives to make ownership clear.
- 2026-08-20: agents test their own work before they return it for review. Spend limits control cost.
- 2026-09-03: a Priority tab in the Inbox splits urgent notifications from items that can wait.
- 2026-09-14 and 2026-09-24: Loops react to changes in status and assignee. Projects get a lead team.
- Gaps / bias notes: Release notes describe features, not results. Software-team focus. No data on adoption or time saved.
