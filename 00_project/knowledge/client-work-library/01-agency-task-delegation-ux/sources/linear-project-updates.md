# Initiative and project updates (Linear docs)

- Type: official doc
- Published: living page, fetched 2026-10-13
- Fetched: 2026-10-13
## Key points
- Each update has one health value: On track, At risk, or Off track. The lead sets it by hand.
- Each update also has a short text. The text covers status and problems. It also gives the next steps.
- Admins set a reminder rhythm (daily, weekly, every two weeks, or custom). Reminders go only to the project lead.
- If the lead posts nothing, the tool sends a second nudge after 1 working day and a third after 2 more days.
- A project shows "Update Missing" when the update is late by one cycle plus 3 days. The health icon turns grey after a long delay.
- An automatic progress summary appears only when progress changed by more than 2 percent.
- The newest update shows on the project overview. Older updates stay in an Updates tab as history.
- Updates can also go to Slack and to the Inbox.
- Gaps / bias notes: Health is a human judgment, not a calculated score. The doc gives no rule for how to pick the value.
