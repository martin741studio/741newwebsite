## Key points
- "My Issues" is one personal list with four tabs: Assigned, Created, Subscribed, Activity.
- The Assigned tab groups work in a focus order: urgent, SLA-bound, blockers, then cycle work.
- Inside each group, the list sorts by priority. Started work shows first.
- The Created tab shows all items the person created, also items from integrations.
- The Activity tab lists recent changes and comments by date.
- The view answers one question for each person: what must I do next.
- Gaps / bias notes: The page does not explain delegated work or filters (the July 2026 changelog adds delegated items to Assigned). Vendor doc.
