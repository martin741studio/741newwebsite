## Key points
- Intake is a holding area for requests. Users with the Guest role (for example clients) submit work items here.
- Guests can set priority and a due date. They can also pick an assignee and labels. Team members can change these later.
- New items have the state Pending. This state is separate from the normal project states.
- Team members accept, decline, snooze, or mark an item as duplicate.
- Accept moves the item into a project state that the reviewer picks. Decline moves it to Cancelled.
- An Open tab shows pending and snoozed items. A Closed tab shows all closed items, for example accepted or declined ones.
- Each item keeps an activity log and comments.
