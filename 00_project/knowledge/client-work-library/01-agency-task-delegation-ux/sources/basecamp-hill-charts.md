# Hill Charts: See where projects really stand (Basecamp)
- URL: https://basecamp.com/hill-charts
- Type: official product page
- Published: living page, fetched 2026-10-13
- Fetched: 2026-10-13
## Key points
- Each block of work has two phases. Uphill means the team still solves unknowns. Downhill means the team only executes.
- The top of the hill means no open problems remain.
- Status attaches to a to-do list, not to each single to-do. This gives a high-level view.
- A person places the dot by judgment. The tool does not calculate the position.
- Each update saves a snapshot to the project history. Managers see movement without a status meeting.
- People can add a comment to an update and others can reply.
- A dot that does not move shows unclear scope. The fix is to split the list into smaller lists.
- Gaps / bias notes: No date on the page. The method fits small project teams. It does not cover workload, owners, or clients.
