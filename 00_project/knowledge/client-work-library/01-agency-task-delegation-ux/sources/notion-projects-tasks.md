## Key points
- The template uses two linked databases. Projects are the parent. Each task links to one project.
- Tasks have an assignee, a due date, and a status.
- A "Mine" view filters to the person who opens it. One view serves every team member.
- A completion property counts done tasks and shows a progress bar per project.
- A timeline view shows projects by start and end date. Overlaps show capacity problems.
- The guide recommends that key project facts, meeting notes, and documents live on the project page.
- Gaps / bias notes: No date. No health status, no workload limits, no delegation notes. Percent-done hides risk.
