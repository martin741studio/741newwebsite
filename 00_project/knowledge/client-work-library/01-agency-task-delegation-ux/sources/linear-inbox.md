## Key points
- The Inbox is the personal notification center. It holds events on items you created, own, or were mentioned on.
- A Priority tab splits items that need attention from other updates. Users can change the Priority filter.
- Snooze hides a notification until a set time. Then it comes back.
- Reminders can be set on issues, documents, projects and initiatives. They arrive in the Inbox at the set time.
- Keyboard keys mark read or unread and delete read items in bulk.
- Quick search filters by title, type, assignee, team, project and priority.
- The Inbox keeps up to 2,000 open notifications. Users cannot archive notifications or choose which ones arrive.
- Gaps / bias notes: The Inbox shows events, not a ranked work list. "My Issues" holds the work list. Vendor doc.
