## Key points
- Six agent jobs work today: status roll-ups, tasks from meeting notes, dependency checks, risk flags, report drafts, week-in-review summaries.
- Agents fail at priority calls. They lack the context from conversations.
- Agents fail at people decisions, for example reassignment and nudges.
- Badly bounded agents can mark work as done without a check ("hallucinated completion").
- Start with one reversible job, for example the weekly status draft.
- Give clear stop points, for example "draft only, change nothing".
- Agents can read and draft. A human must approve changes to dates, owners, or anything sent outside the team.
- Keep a record of every agent action and a way to undo it. Review output for one week before you add more jobs.
- Gaps / bias notes: Vendor blog, but the advice is tool-neutral. No measured results.
