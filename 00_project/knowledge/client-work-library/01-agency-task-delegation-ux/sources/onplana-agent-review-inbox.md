## Key points
- You delegate to an agent with the same action as for a person. The tool posts an @mention.
- The agent takes the work on its next sync. Its queue is visible and a person can stop it.
- Agent output goes to a review inbox: drafts, status reports, email drafts, proposed subtasks.
- Nothing goes live before a person reviews it.
- Approve publishes the edited version or the original draft. The approval goes into the audit trail under the approver's name.
- Reject stops the output. The rejection note stays attached, and the agent reads it on the next run.
- The article recommends a close read of the first sentence of each draft. Skim the rest only when needed.
- Judgment calls and anything a customer sees stay with a person.
- Gaps / bias notes: Vendor promotes its own product. No formal risk levels. The survey figures come second-hand.
