# A08 — AI Agents Push Humans Out of the Loop (position paper)

- Authors: Margaret Mitchell, Avijit Ghosh, Samir Passi
- URL: https://arxiv.org/abs/2608.23642
- Type: research position paper (arXiv)
- Publish date: submitted 2026-08-24 (v3 online 2026-09-06)
- Fetch date: 2026-10-13 (abstract and metadata only)

## Key points (paraphrased from the abstract)

1. "Keep a human in the loop" is not a simple fix for agent risk.
2. Current agent designs make effective oversight harder.
3. The skills needed for oversight degrade with long use of automation (skill atrophy).
4. The needs of the overseer should rank as high as agent capability.
5. Proposes design-level affordances that help overseers use critical judgement, plus organisational protocols that counter skill atrophy.
