## Key points (paraphrased)

1. A weekly scorecard holds 5 to 15 numbers, reviewed every week. No more than 15.
2. Every number has exactly **one owner**. Shared ownership means no ownership.
3. Prefer **leading indicators** that the owner can move this week.
4. Each number has a clear weekly goal (threshold), so it reads on-track or off-track.
5. Show a 13-week trend for each number.
6. Include the vital basics: revenue, cost, cash.
7. Build the company scorecard first. Department or client scorecards later.
8. If a number is red three weeks in a row, question both the goal and the measure.
9. The first version will be wrong. Improve it weekly.
10. The article also describes letting AI pull the numbers into the sheet.

## Use for 741

Template for a per-client mini-scorecard (3 to 5 numbers each) plus a 741 company scorecard. The grill should check "does every active client have an owner and a weekly goal for each number?"

Short quote: "Co-ownership is non-ownership."
