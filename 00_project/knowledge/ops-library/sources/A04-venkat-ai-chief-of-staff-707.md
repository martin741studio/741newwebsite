## Key points (paraphrased)

1. A daily brief lands in Slack at 07:07 every morning: headlines, schedule, tasks, content ideas, flagged items (e.g. forgotten subscriptions).
2. The brief ranks items against **six standing priorities** written down once, with family first. Ranking is rule-based, not ad hoc.
3. Loop of five steps: inputs, synthesise, plan, execute, outcomes.
4. Three specialised agents: an email agent, a news agent, and the brief agent ("chief of staff") that merges everything and writes the final ranked brief.
5. The brief agent reads **yesterday's memory** so it can recall commitments and patterns across days.
6. Agents run on schedules via GitHub Actions (cloud), not on the laptop.
7. The system protects personal time explicitly (calendar guard).

## Use for 741

Shows the value of fixed standing priorities as the ranking key and of "yesterday's memory" feeding today's brief. A 07:07 start also avoids the on-the-hour delay noted in O1.

Short quote: "Every morning used to feel like detective work."
