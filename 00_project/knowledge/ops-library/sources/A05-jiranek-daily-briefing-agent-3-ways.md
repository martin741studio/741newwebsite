## Key points (paraphrased)

1. Start by defining the agent's job in one sentence. His: a useful morning brief.
2. Compact brief structure with four blocks: **TODAY**, **FIXED** (commitments that cannot move), **WATCH** (risks to monitor), **NEXT** (what follows).
3. Three build levels: (a) a scheduled AI task with standing instructions. (b) an orchestrated workflow when you need control over data flow. (c) own code when the brief becomes critical infrastructure.
4. Start with level (a) for a short feedback loop. Move up only when a concrete need justifies the extra machinery.
5. Use the private sources you already have (calendar, GitHub, task tracker).
6. Decide data boundaries and permissions on purpose: give the agent narrow read rights and narrow action rights.
