# A11 — Four Check-In Questions Worth Asking (And One to Drop)

- Author: Steven Macdonald (OKRs Tool)
- URL: https://www.okrstool.com/blog/check-in-questions
- Type: practitioner article (OKR weekly check-ins)
- Publish date: 2026-08-04 (shown on page)
- Fetch date: 2026-10-13

## Key points (paraphrased)

1. Four questions for a weekly goal check-in:
   - What moved this week?
   - What is off track, and why?
   - Where do you need help?
   - How confident are you now, on a scale of 1 to 5?
2. Drop the question "Are we still on track?" because it invites a reflex "yes".
3. A confidence score over time shows a stalling goal before the result shows it.
4. Check-ins only help if someone acts on the answers.
5. The article cites a 43% lift in OKR completion from weekly check-ins (vendor claim, source not verified here).
6. A goal programme that depends on one person tends to die quietly.

## Use for 741

Four ready questions for the weekly per-client review. The 1–5 confidence score per client goal is a cheap leading signal for the grill.
