# A06 — Gate Fatigue: When AI Approval Stops Working

## Key points (paraphrased)

1. Gate fatigue starts when the number of approval requests exceeds the reviewer's attention.
2. Review then turns into queue-clearing: the approver clicks yes to empty the list.
3. Gates pile up over time and are rarely checked for whether they still match the risk.
4. A very high approval rate can be a warning sign (fatigue), not proof of good agent work.
5. Bulk approval lowers review quality and lets critical items slip through.
6. Watch signals: time spent per review, approval rate, and reversals after approval.
7. Example from marketing: routine approvals get fast-tracked and a major error passes.
8. Match review effort to risk. Show evidence next to each request.

## Use for 741

Guard against a grill that asks Martin 30 trivial questions. Limit the daily queue, tier by risk, and show evidence on each card.

Short quote: "Reviewer's judgment is a limited resource."
