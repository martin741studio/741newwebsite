## Designrichtung (Kurzfassung der Prompt-Regeln)

- Gleiches Design-System wie die Startseite (Farben #783ca0, #5b2d80, #f8f3fb, ein Oliv #aabe1e nur für Buttons, Serifen-Headline, Poppins-Charakter, runde Karten, Lavendel-Linienzeichnung auf dunklen Bändern).
- Rhythmus: hell, hell, hell, hell, hell, hell, hell, DUNKEL (Abschnitt 8), hell, hell, hell, DUNKEL (Abschnitt 12).
- Zwei Fotos von Daniela bei der Arbeit (Beratung in Abschnitt 3, Kräutergarten in Abschnitt 6) werden erzeugt, mit echtem Gesicht aus den Portraits. Sie stehen später auf der Shoot-Liste.
- Kein erfundener Text, keine Tagline, kein Text im Foto.

## Do-nots (gelten für den Prompt)

- Keine zweite erfundene Person als Behandlerin, nur die Frau aus den Portraits.
- Kein Stockfoto-Look.
- Kein Text außer dem exakt vorgegebenen, keine erfundene Tagline.
- Nur eine Button-Farbe (Oliv).
- Keine Vorher-Nachher-Darstellung, keine Krankheits-Symbolik.
