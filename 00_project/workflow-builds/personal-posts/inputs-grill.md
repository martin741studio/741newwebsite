# Inputs grill — personal-posts

Source: live grill with Martin in the chat-base session, 2026-10-22. Confirmed by Martin before this build started. Carried into this build chat as the brief.

## 1. The Job

Martin dictates or types a raw thought. The workflow turns it into finished social posts in Martin's own personal voice (not a client's), for his own/741 channels. One source draft becomes 4 platform versions: Instagram, Facebook, LinkedIn, X/Twitter. Instagram and Facebook posts also get an image, built through the existing social-visuals-workflow. Martin reviews and gives his own explicit go per post before anything goes anywhere. He posts it himself.

## 2. Runtime Surface

Terminal (Claude Code), inside this project (741website). Martin dictates or types directly into a chat under this project.

## 3. Frequency / Cadence

On demand. 3-4 times a week target, not daily, not on a forced schedule. Martin triggers it each time with a new thought.

## 4. Hard Limits (must never happen)

- Never auto-post or auto-schedule to any platform, on any channel. Text and image go to Martin ready; he posts himself.
- Never invent or exaggerate a number or a result. Every claim must be real and sourced (house rule `claims-need-real-data`).
- Never name a client or use a client's real result without that specific client's own go for that specific post. Default without a client go: anonymized (industry + number, no name, no logo).
- Never leak tool or platform-vendor jargon into the post copy itself.
- Never skip the slop check before a draft reaches Martin.
- Never build a second image pipeline — image posts route through the existing social-visuals-workflow.

## Other confirmed design points (treated as settled, not open)

- Language: English.
- Tone: direct, willing to be hard or polarizing. No motivational-poster lines, no false-modesty humblebrag, no hedge-everything corporate voice.
- Topics: agency insights / build-in-public, SEO/marketing opinions, client results (anonymized by default), personal/mindset pieces.
- Voice source: one live interview (see `voice-interview-raw.md`), since Martin has no existing post history to learn from.
