## Edge cases surfaced by this run (for Step 3 build + Step 4 testing)
1. A card must never assert a stale fact as true — verify-or-ask, every time a specific name/number from memory appears in card text.
2. When the real situation is "the channel choice is already correct, the problem is execution," Round 1 should present that as a confirmation, not force a from-scratch Core Four re-derivation — the skill body needs a branch for "diagnosis already exists" vs. "starting cold."
3. "What should pause" needs an explicit "nothing" option, not just a list of things to stop — over-eagerly suggesting pauses when nothing actually needs to stop would be a false finding.
