# 741 agent jobs

One job description per 741 AI agent, the roster, the weekly reviews, and the inbox/outbox handoff folders.
Skill: `.claude/skills/agent-job-descriptions/` (`/agent-job-descriptions`). Knowledge: `00_project/knowledge/agent-job-library/`.

- `roster.json` / `roster.md` — every agent (id, type, where it runs, status, placed copies, last grade). Edit with `scripts/roster.py`.
- `<id>.md` — the description (source of truth). Placed copies live in `.claude/rules/agents/<id>.md` or inside a scheduled task's SKILL.md and are generated by `place.py`.
- `reviews/<ISO-week>/<id>.md` — Friday reviews; `<id>-evidence.md` is the collected evidence.
- `<id>/inbox/` — task handoffs from client chats or the morning grill (template in the skill references); `<id>/outbox/` — reports.
