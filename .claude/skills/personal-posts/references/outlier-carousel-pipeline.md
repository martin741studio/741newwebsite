# Outlier carousel pipeline — business account

Confirmed working end to end 2026-10-29 (SEO/AEO/GEO carousel, after an earlier rejected attempt). Use this ordered pipeline whenever a carousel (or carousel+video-cover) is built from a picked outlier video, business account. It sits on top of the normal `## Workflow` in `SKILL.md` — steps 0, 1 (or G0-G4), 3, 4, 9, 11, 12 there still apply; this file fills in steps 5-10 for this specific format with the order Martin requires.

- [ ] 1. **Pick the outlier.** From `references/outlier-content-notes.md` or a fresh vidIQ Research pass (`content-loop-vidiq-outliers.md`), pick ONE real outlier video that matches a pillar.
- [ ] 2. **Pull the real transcript — mandatory, never skip.** `references/outlier-content-notes.md` §"Mandatory step before writing: pull the real transcript". Confirm the exact video (`firecrawl_search` + `firecrawl_scrape` with the `youtube-com videos/video_details` Alexandria capability), then `mcp__Apify__call-actor` (`actor: "johnvc/YoutubeTranscripts"`, input `{"youtube_url": "<url>", "languages": ["en"], "output_formats": ["text"]}`), then `mcp__Apify__get-dataset-items`. Never draft from a guessed summary of the title/thumbnail.
- [ ] 3. **Mine the transcript for real substance.** List every distinct point/claim/step it actually makes (not just the headline framing) — this list is also what Martin uses to pick follow-up posts from the same video later. Each point should be usable as its own future post, not just filler for this one.
- [ ] 4. **Write the full slide-by-slide text first, nothing visual yet** (`content-workflow-order-text-before-video.md`, HARD rule — Martin has said this many times). Ground every slide in the real transcript content from step 3, translated/adapted into 741's own voice and grounded in a real 741 proof point where one fits (`claims-need-real-data`). Cover slide needs a real hook per `producer-formats.md` §Carousel ("Cover = the hook... one specific, contrarian or curiosity hook", ≤12 words for the main line). Never name the source channel/creator in the text (`no-method-sources-in-deliverables`).
- [ ] 5. **Slop-check the text**, `python3 00_project/content-writing-skill/scripts/deslop_de.py --claims <claims.json> <carousel.txt>`, 5/5 before showing Martin anything.
- [ ] 6. **Show Martin the text only, ask for the go** (AskUserQuestion card) before touching any image or video. Fix and re-lint on request.
- [ ] 7. **Pick the visual asset — never the same image/video twice.** `content-loop-vidiq-outliers.md` §"Bild-Varianz, kein Wiederverwenden". Order of preference: an unused real photo/video still of Martin first (e.g. a frame from a video he already gave for this purpose), only then a freshly generated image via one of the existing image workflows. Confirm with Martin if it's not obvious which asset he means.
- [ ] 8. **If the cover is Martin's own video, not a still:** crop it to the carousel's own ratio (`ffmpeg -vf "crop=<w>:<h>:<x>:<y>"`), find the span where he stays fully in frame (sample frames, build a contact sheet if unsure), trim to that span. Then render the SAME headline/hook + logo/counter/footer chrome used on the image slides as a transparent PNG (headless Chrome, `--default-background-color=00000000`, file:// URL must be absolute) and composite with `ffmpeg -filter_complex "[0:v][1:v]overlay=0:0:format=auto" -map "[v]" -c:v libx264 -pix_fmt yuv420p -an`. This machine's ffmpeg has no `drawtext`/libfreetype — text always comes from a rendered PNG, never an ffmpeg text filter. Full detail: `producer-formats.md` §Carousel, "Video cover".
- [ ] 9. **Render the remaining slides** with `scripts/build_carousel_photo.py`. When a video occupies position 1, pass `"start": 2, "total": <N+1>` in spec.json so the on-slide counters (`2/8` etc.) match the video being item 1 — do not leave them reading `1/7`. Keep the `==...==` highlighter wrapped around a WHOLE line, never a single word.
- [ ] 10. **Read every slide (and the video, at 2-3 timestamps) back before showing Martin** — check numbering, highlighter placement, text fit, subject stays in frame throughout the video.
- [ ] 11. **Caption.** Hook line, 1-2 body paragraphs carrying the real substance, a real 741 proof point, a keyword comment-CTA (`producer-formats.md` §Carousel, "Keyword CTA" — Instagram only, never LinkedIn, no auto-DM yet per `decisions.md` 2026-10-29), and a closing question Martin would actually want answered. Slop-check to 5/5.
- [ ] 12. **Final go on the whole piece**, then log to `fertige-posts-texte.txt` (newest entry on top, caption + slide texts for reference) and `run_log.py write content-prod done --account business "<note>"`.
- [ ] 13. **Upload to Drive (Martin, 2026-10-29 — do not skip, this is the actual finished-content home, not just the local folder).** Drive path: `My Drive > Socials Martin > Fertige Posts` (folder ID `1OpBU1V9Gf-Bm7MYI2aNHl4DY7xxmAQ49`, parent "Socials Martin" ID `1iQzznSaQ5eY8hRNEKbziziCtkBwbmju_` (IDs verified in Chrome 2026-10-30, see memory drive-socials-martin-folder-ids)). Create a subfolder named `<date> <post-name>` (e.g. "2026-10-29 Die Eselsbruecke"), then upload every slide/video plus `caption.txt` into it. Binary files never go through the Drive MCP tool — use Claude in Chrome: open the folder, click "New", then run a JS click (not a real mouse click, which would open a native OS file picker the agent cannot see) on the "File upload" menu item:
  ```js
  const items = Array.from(document.querySelectorAll('[role="menuitem"]'));
  const target = items.find(el => el.textContent.trim().startsWith('File upload'));
  target.click();
  ```
  then `find` the resulting hidden file input and `file_upload` the local paths to it directly. Keep each `file_upload` call's combined size under 10 MB — split a video into its own call when images+caption+video would exceed that. Finally, replace the top-level `fertige-posts-texte.txt` in the `Fertige Posts` folder with the current local copy (upload same filename, Drive offers "Replace existing file" — pick that).
