## Step 4 research detail
Log every call: `python3 scripts/log_research_calls.py <out_dir> add <tool> "<query>" <hits>` (`hits` = results about the client's category and area, not the raw count).
- `firecrawl_search` (web) for "<service> <city> reddit", "best <category> <city>", "<service> <city> forum/Quora", and the client's name + city. Reddit threads cannot be scraped directly: use the search snippets, never retry a direct Reddit scrape.
- Blog roundups and review-site lists from those results (`firecrawl_scrape` on non-Reddit pages when the snippet is not enough). Page too large to read: save it, grep the saved file for the client's name and the keyword, log the hit count; still unreadable: log it as unreadable. Never summarize a page you did not read.
- The client's own reviews/FAQ page/DMs if on file; competitor comment threads only when a competitor post URL (not just a domain) is on file.
- Rank with playbook-notes §G: top-20 % buyers' problems, sales-call objections, save-worthy answers, niche specificity. Keep 5-10 questions, each with its source.
