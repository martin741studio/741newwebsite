# 741 Studio Website Codebase & Database Overview

This document provides a comprehensive overview of the 741 Studio website repository, its architecture, build system, and the current state of ongoing development. It is designed to be passed to another AI agent to provide immediate context on how this project operates.

## 1. Project Overview
This repository contains the source code for the **741 Studio Website** (`741.studio`), a digital growth and automation agency. The site is a static, highly optimized frontend build using HTML, CSS (Webflow-exported originally, now manually managed), and JavaScript. 

The project uses a custom build system orchestrated by **Vite**, focusing on a component-based architecture using Handlebars-like partials (even though they are `.html` files) to assemble pages dynamically during the build process.

## 2. Directory Structure & Architecture

The repository is structured numerically, but the primary focus of active development is in the `04_site` and `dist` folders.

- `04_site/` - **The Core Source Directory**
  - **`index.html`**: The main English homepage.
  - **`pages/`**: Contains all English subpages (e.g., `about.html`, `local-seo.html`, `google-ads-1.html`, and a deep `blog/` subdirectory).
  - **`components/`**: Contains reusable HTML partials like `header.html` and `footer.html`. These are injected into the pages during the Vite build process.
  - **`sections/`**: Contains reusable page sections (e.g., `hero.html`, `professional-tools.html`).
  - **`de/`**: The German translation of the site. It mirrors the root structure (`de/index.html`, `de/pages/`, etc.).
  - **`public/`**: Static assets that are copied directly to the build folder (e.g., `favicon.ico`).

- `dist/` - **The Production Build Directory**
  - This is the output folder generated by Vite (`npm run build`). 
  - It contains the compiled HTML, processed CSS/JS assets (with cache-busting hashes in `assets/`), and is what actually gets deployed to the live server.

- `.agent/` - **Data & Content Repository**
  - Contains Markdown files (like `PaidAdsCopy.md`) used to store copywriting, ad variations, and content strategy data.

- `_johni_jaya_archive/` - **Legacy / Utility Scripts**
  - Contains PHP scripts (like `check_reinfection_741.php`) likely used for server-side health checks or legacy WordPress cleanup.

## 3. Build & Deployment System

- **Vite (`vite.config.ts`)**: The build tool configured with a custom plugin to stitch together the HTML components (`header`, `footer`) into the main pages. It handles multiple entry points, traversing the `04_site` directory (including the `de` folder and `blog` folders) to generate a fully static site in `dist/`.
- **Deployment (`upload.js`)**: A custom Node.js FTP deployment script. It takes the contents of the `dist/` folder and uploads them directly to the live server (`185.2.31.101`). 
- **Workflow**: `npm run build` -> `node upload.js`
